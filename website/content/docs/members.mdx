title: 邀请朋友

## 公开分享 vs 邀请朋友 [#选择分享方式]

| 需求 | 用哪个 | 对方权限 |
| --- | --- | --- |
| 给别人看一份作品 | [公开分享](/zh/docs/sharing) | 免登录，只读快照 |
| 让朋友自己创作、接自己的 Agent | **邀请朋友** | GitHub 登录，拥有独立项目、设备和存储 |

<Notice title="前提条件">
  仅自托管实例的管理员可以发邀请，且需要先按 [部署自己的实例](/zh/docs/self-hosting) 配置好 GitHub
  登录。不要把管理员访问密钥发给朋友。
</Notice>

## 管理员：怎么发邀请 [#管理员创建邀请]

<Steps>
  <Step title="设置共享容量">
    进入「存储设置 → 实例共享」设好总容量上限，再决定给朋友分多少额度。
  </Step>
  <Step title="创建邀请链接">
    进入「成员管理」点「邀请朋友」，填对方的 GitHub 用户名和共享容量（填 `0`
    表示不分配共享容量，对方可绑自己的 S3）。
  </Step>
  <Step title="发给朋友">
    邀请链接**只在创建时显示一次**，绑定指定 GitHub 账号，7
    天有效，限用一次。丢了或过期直接撤销重发即可。
  </Step>
</Steps>

## 朋友：接受并开始使用 [#朋友接受邀请并开始使用]

1. 打开邀请链接，用对应的 GitHub 账号登录，直接进入你的独立空间（看不到管理员或其他人的私有作品）。
2. 按 [设备与 CLI](/zh/docs/remote-cli) 配对本地 Agent，也可以在「存储设置 → 我的 S3」绑自己的对象存储。

## 管理成员 [#调整额度与暂停访问]

管理员可随时调整额度、撤销未接受邀请或暂停成员访问。暂停后登录态与 CLI 授权立即失效，文件保留；恢复后重新登录配对即可。

## 邀请打不开？ [#邀请打不开]

检查链接是否已过期（7 天）、已使用或已撤销，以及当前登录的 GitHub 账号是否和受邀账号一致，不行就让管理员重发一条。
