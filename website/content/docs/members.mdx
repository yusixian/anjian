---
title: 邀请朋友
description: 朋友想自己创作时，为他开通独立空间。只展示作品时，直接使用公开分享。
---

## 选择分享方式

| 目的           | 方式                      | 对方的权限         |
| -------------- | ------------------------- | ------------------ |
| 看一份作品     | [公开链接](/docs/sharing) | 免登录只读查看快照 |
| 管理自己的作品 | GitHub 账号专属邀请       | 登录后进入独立空间 |

<Notice title="由实例管理员发起邀请">
  需要能被朋友访问的自托管实例，并已配置 GitHub 登录。本机 localhost
  地址无法直接发给远方的朋友使用。不要把管理员访问密钥当作邀请链接发送。
</Notice>

## 管理员：创建邀请

<Steps>
  <Step title="先确认共享容量">
    进入「存储设置 → 实例共享」，设置总容量。成员额度是共享容量内的个人上限，不是额外的物理磁盘。
  </Step>
  <Step title="填写朋友的 GitHub 用户名">
    在「成员管理」点击「邀请朋友」，填写用户名和共享容量额度。0 表示不分配共享容量。
  </Step>
  <Step title="复制邀请链接，发给这位朋友">
    链接仅在创建时显示，绑定指定 GitHub 账号，7 天有效，只能接受一次。丢失或过期时可撤销并重新邀请。
  </Step>
</Steps>

## 朋友：接受邀请并开始使用

打开邀请链接，使用被邀请的 GitHub 账号登录。接受后进入自己的空间，管理自己的作品与设备，不会看到管理员的私有作品。

要让本地 Agent 上传作品，再到[设备与 CLI](/docs/remote-cli)完成配对。日常浏览作品不需要重复配对。成员可以配置[自己的 S3](/docs/storage)。

## 调整额度与暂停访问

管理员可以修改成员额度、撤销待接受邀请或暂停成员访问。暂停使原会话、设备授权和私有资源链接失效，但保留文件。恢复后成员需重新登录并重新连接设备，旧授权不会自动恢复。

## 邀请打不开

检查链接是否过期、已接受或已撤销，以及当前 GitHub 账号是否与邀请一致。让管理员重新生成邀请，不要用共享管理员密钥绕过身份限制。
