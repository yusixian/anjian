title: Devices & CLI

If you're using a self-hosted Anjian instance (like `https://anjian.cosine.ren`), your local Agent syncs artifacts and comments via CLI. You only need to pair each machine once.

> Below, `anjian` refers to your installed binary, wrapper, or `node /abs/path/to/anjian/artifacts/dist/cli.cjs` (see [Connect an Agent](/en/docs/agent)).

## 1. Check skills and current binding first [#install-and-authorize]

Always check whether this project is already linked before starting a new login:

```bash title="Terminal · Discover skills and check status"
anjian --help
anjian skills list
anjian skills get artifacts
anjian skills get artifacts --reference remote.md
anjian remote status --json
```

## 2. Pair your device [#pair-device]

Run this only when unauthorized, expired, or revoked:

```bash title="Terminal · Pair device"
anjian login https://your-anjian-domain --name "My MacBook"
```

Your browser opens the pairing page (add `--no-open` on headless machines and open the printed URL manually):

1. Sign in to the workbench if prompted.
2. Verify the **device name** and **12-character pairing code**.
3. Pick which projects this device can access and click **Approve connection**.

Pairing codes expire in 10 minutes; device credentials stay valid for 90 days.

## 3. Link a local project [#link-an-artifact-project]

Inside your local project directory:

```bash title="Terminal · Link project"
anjian link
anjian remote status --json
```

If you have multiple server projects, pass `anjian link --project <project-id>`.

## 4. Push and pull artifacts [#upload-and-pull]

```bash title="Terminal"
anjian push --artifact document/plan  # Upload local changes
anjian check --artifact document/plan # Validate structure and assets
anjian pull --artifact document/plan  # Download latest from server
```

- **Source files only**: Syncs `.anjian/artifacts/<type>/<id>/` without comments, history, dotfiles, or symlinks. Limit: 1,000 files and 32 MiB.
- **No silent overwrites**: `push` and `pull` both stop on conflict. To keep a local backup while pulling, run `anjian pull --artifact <id> --backup-local` and merge manually.

## 5. Manage or revoke devices [#review-and-revoke-devices]

Open **Devices & CLI** in the workbench sidebar to revoke any device at any time (existing artifacts and comments stay untouched). From the terminal:

```bash title="Terminal"
anjian logout https://your-anjian-domain
anjian unlink
```

Credentials are stored in `~/.anjian/client/` by default (override with `ANJIAN_CLIENT_HOME`).

## Common connection errors [#connection-problems]

Public instances require `https://` matching the server's configured origin. Re-run `login` on 401, check project permissions on 403, and retry shortly on 429.
