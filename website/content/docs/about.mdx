## 项目来源

案间（Anjian）基于 [Innei/ryugi v1.51.2](https://github.com/Innei/ryugi/tree/v1.51.2)（提交 `6054b65ab9b2208a234a78632eb065cfeb3eb166`）分叉并独立维护，专注个人使用、中文体验、本机运行和自托管部署。

感谢 Innei 与 Ryugi 贡献者，也感谢 Jesse Vincent 与 [Superpowers](https://github.com/obra/superpowers) 贡献者。完整来源记录见仓库的 `UPSTREAM.md`。

## 许可证

| 目录范围 | 许可证 |
| --- | --- |
| `artifacts/` 应用及构建产物 | [AGPL-3.0-only](https://github.com/yusixian/anjian/blob/main/artifacts/LICENSE) |
| Skills、集成脚本与文档 | [MIT License](https://github.com/yusixian/anjian/blob/main/LICENSE) |
| 第三方依赖 | 遵循各自开源协议 |

项目改名不改变继承代码的许可证。如果你修改后作为网络服务对外提供，需要遵守 AGPL-3.0 的对应源码开放要求。

## 独立维护 [#维护与更新]

案间不接入 Ryugi 官方云服务，也不自动下载上游发行包。一切构建、更新和部署均来自本仓库源码与 Releases。

[前往 GitHub 查看源码](https://github.com/yusixian/anjian)
