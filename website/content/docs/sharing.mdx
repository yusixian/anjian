description: 发布一份只读快照，让朋友无需登录即可查看。

## 创建公开链接

在作品页或作品卡片点击「分享」，选择有效期，再点击「创建公开链接」。支持画板、文档和 HTML。有效期可选 1 天、7 天、30 天或长期有效。

分享默认关闭。公开前检查完整作品与附件：画板会包含全部页面，不只包含当前页面。通过「预览访客页面」检查后再把链接发给朋友。

## 朋友能做什么

访客不需要账号即可打开链接。画板保留页面导航、缩放和平移、图层树、元素选择、尺寸和样式检查、代码查看与复制；文档和 HTML 保留阅读与预览。

访客不能评论、修改属性、调整参数或访问其他私有作品。只读无法阻止截图、复制文字或保存已传输的资源；持有链接的人可以转发。

## 更新和收回

| 操作           | 结果                                       |
| -------------- | ------------------------------------------ |
| 更新分享       | 发布当前作品的新快照，链接与到期时间不变   |
| 重置链接       | 旧链接失效，已发布内容与到期时间保留       |
| 关闭分享       | 停止公开访问，原作品和批注保留             |
| 到期后重新创建 | 生成新的链接                               |
| 移入回收站     | 撤销该作品的分享；恢复作品不会自动重新公开 |

修改草稿不会自动更新公开版本。已打开的访客页会周期性检查分享状态，但已经保存的内容无法收回。

## 网络与容量

服务器必须持续运行并能被朋友访问，`localhost` 链接不能直接跨设备使用。公网部署参见[自托管](/docs/self-hosting)。

单份快照最多 32 MiB、1,000 个源文件。发布更新时需要短暂容纳新旧快照，因此需要预留容量。匿名请求有突发限流，出现 429 时按提示等待。

公开预览限制外部网络、表单提交和弹窗，外部脚本、字体、图片或接口可能无法正常工作。详见 [HTML 预览](/docs/html)。
