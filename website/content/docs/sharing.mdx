## 创建公开链接

打开任意画板、文档、HTML、白板或幻灯片，点「分享」→ 选有效期（1 天 / 7 天 / 30 天 / 长期有效）→ 点「创建公开链接」。评审文档还可以勾选一并公开同项目里引用的作品。

公开链接默认关闭，发布的是**静态快照**：

- 画板包含**全部页面**，发出去前建议先点「预览访客页」确认。
- 不含评论、编辑历史或你的其他私有作品。

## 访客能做什么 [#朋友能做什么]

拿到链接的人**无需登录**即可打开：画板可切页、缩放、查图层和复制代码；文档和 HTML 可正常阅读与运行本地脚本。访客不能评论、不能改参数，也看不到你的其他作品。

> 只读链接挡不住截图或转发，发布前确认无敏感信息。

## 更新、重置与关闭 [#更新和收回]

| 操作           | 效果                                         |
| -------------- | -------------------------------------------- |
| **更新分享**   | 把最新草稿同步到当前快照，原链接和有效期不变 |
| **重置链接**   | 立刻废掉旧链接并换新链接，内容不变           |
| **关闭分享**   | 停止公开访问，原作品和评论不受影响           |
| **移入回收站** | 自动关闭分享；恢复作品后需手动重开           |

## 限制 [#网络与容量]

- `localhost` 链接无法跨设备打开，公开分享需要先 [部署自己的实例](/zh/docs/self-hosting)。
- 单份快照上限 **1,000 个文件、32 MiB**；更新时会短暂同时占用新旧两份空间。
- 公开页在沙盒中运行，会拦截外部 API 请求、表单提交和弹窗。
