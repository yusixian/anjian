## Finding artifacts [#find-artifacts]

Filter the library by **project** and **type**, sort by update time or name, or press `⌘K` / `Ctrl+K` to search across all projects.

Document thumbnails display the title and use light lines to represent the body. Open a card to read the full document.

## Bulk actions [#organize-in-bulk]

Click **Select** to enter bulk mode:

- `Shift` + click: Select a range
- `⌘A` / `Ctrl+A`: Select all visible results
- `Esc`: Exit selection mode

Click **Move to Trash** and confirm the listed items.

## Trash & recovery [#restore-and-permanently-delete]

- **30-day retention**: Trashed artifacts keep their assets, comments, and history for 30 days before automatic cleanup.
- **Easy restore**: Click **Undo** right away or restore later from **Trash** with the original URL intact. Deleting forever cannot be undone.

## Local & server copies [#local-and-server-copies]

- **Local files stay safe**: In self-hosted mode, trashing removes the server copy only—your local project files are untouched.
- **No accidental re-uploads**: Trashing turns off public sharing, and pushing a trashed ID is blocked. Restore it first, or use a new ID after permanent deletion.
