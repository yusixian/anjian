## File layout & runtime UI [#pages-and-resources]

HTML artifacts live in `.anjian/artifacts/html/<id>/` with `index.html` as the entry point (the page `<title>` becomes the artifact title). Keep assets inside the folder with relative paths.

To add Anjian parameter panels or feedback controls, have your Agent read the bundled skill via CLI (setup in [Connect an Agent](/en/docs/agent)):

```bash
anjian skills get artifacts
anjian skills get artifacts --reference html.md
anjian skills get artifacts --reference ui.md
```

## Sandboxed preview [#isolated-previews]

HTML artifacts run in an isolated origin so scripts can't touch your workbench session:

- **Private preview**: Scripts run normally, and you can highlight text to send selection feedback to a local Agent.
- **Public shares**: External API requests, form submissions, and popups are blocked—bundle fonts, styles, and images inside the folder if you want them visible in public snapshots.

## Troubleshooting a blank page [#debug-and-check]

1. Check that `index.html` is complete and valid;
2. Verify all assets use relative paths inside the artifact folder;
3. Run `anjian check --artifact html/<id>` to catch broken paths or syntax warnings;
4. Open browser DevTools to inspect script errors or sandbox blocks.
