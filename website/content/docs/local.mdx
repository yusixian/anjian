## 方式一：下载安装包（最快） [#安装与启动]

到 [GitHub Releases](https://github.com/yusixian/anjian/releases) 下载对应系统的归档和 `.sha256` 校验文件（包内已自带 Node.js，解压就能跑）：

- **macOS**：Apple 芯片选 `darwin-arm64`，Intel 选 `darwin-x64`，校验用 `shasum -a 256 -c <校验文件>`。
- **Linux（glibc）**：`x86_64` 选 `linux-x64`，`aarch64` 选 `linux-arm64`，校验用 `sha256sum -c <校验文件>`。

解压后直接运行包内的 `./anjian start --project-dir /绝对路径/你的项目 --no-open --foreground`。详细步骤见 [安装说明](https://github.com/yusixian/anjian/blob/main/docs/install.md)。

## 方式二：从源码构建 [#源码构建]

需要 Git、Node.js（推荐 22）和 pnpm：

<Steps>
<Step title="克隆并构建">

```bash title="终端"
git clone https://github.com/yusixian/anjian.git
cd anjian/artifacts
pnpm install --frozen-lockfile
pnpm build
```

建议顺手配一个别名，后面文档里的 `anjian` 命令都能直接复制运行：

```bash title="可选：写入 ~/.zshrc 或 ~/.bashrc"
alias anjian="node /你的路径/anjian/artifacts/dist/cli.cjs"
```

</Step>
<Step title="启动你的作品项目">

把路径换成你想存放作品的任意目录：

```bash title="终端"
anjian start --project-dir /绝对路径/你的项目 --no-open --foreground
```

</Step>
<Step title="打开浏览器">

复制终端输出的完整 URL（带访问参数）到浏览器打开。刚启动时作品库为空，下一步去 [创建第一份作品](/zh/docs/first-artifact)。

</Step>
</Steps>

## Linux 开机自启（systemd） [#linux-用户服务]

在带 systemd 的 Linux 上，可以把本机 Hub 装成用户服务（先用 `anjian stop` 停掉手动跑的 Hub）：

```bash
./anjian service install --project-dir /绝对路径/你的项目
./anjian service start
./anjian service status --json
```

停止用 `service stop`，取消开机自启用 `service uninstall`，都不会删除作品。

## 文件保存在哪？ [#作品和服务状态]

- **作品文件**：`<你的项目>/.anjian/artifacts/`
- **服务状态与日志**：`~/.anjian/server/`（含 `hub-events.jsonl` 启停记录）

按 `Ctrl+C` 退出不会删除任何作品。

## 想给手机或朋友看？ [#让其他设备打开]

`localhost` 只能在当前电脑打开。需要跨设备访问、发公开链接或邀请朋友时，请先按 [部署自己的实例](/zh/docs/self-hosting) 上线公网 HTTPS 服务。

## 更新案间

- **安装包用户**：去 Releases 下载新版解压替换入口即可。
- **源码用户**：`git pull` 后在 `artifacts/` 重跑 `pnpm install --frozen-lockfile && pnpm build` 再重启。
