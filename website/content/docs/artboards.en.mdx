## Browsing & inspecting [#browse-and-inspect]

Artboards support multiple pages with fit-to-view and 100% zoom controls. Desktop shortcuts:

- `V`: Select elements
- `H` or hold `Space`: Pan the canvas
- `C`: Add a comment

Click any element to inspect its layer tree, dimensions, computed styles, and live HTML/CSS. Tweaks in the inspector are preview-only and reset on reload—leave a comment when you want your Agent to update the source files.

## Comments, voting & sign-off [#comments-and-option-selection]

- **Pinned comments**: Anchor notes to a specific element, a spot on a board, or blank canvas. Concrete feedback gets cleaner revisions from your Agent.
- **Option voting & verification**: Agents can group boards into choice sets for voting or verification sets for pass/reject sign-off.

## Interactive prototypes & parameters [#interactions-and-parameters]

Most boards are static by default. When a board declares interactivity or parameters, click **Play** to try interactions or **Parameters** to adjust controls live. Images, videos, and mobile browsing are supported.

## File layout (for Agents) [#file-conventions-for-agents]

Artboards live in `.anjian/artifacts/artboard/<id>/` (`canvas.json` + `pages/`). Have your Agent read the bundled skill via CLI (setup in [Connect an Agent](/en/docs/agent)):

```bash
anjian skills get artifacts
anjian skills get artifacts --reference artboard.md
anjian skills get artifacts --reference artboard-prototype.md
```

## Public artboards

[Public sharing](/en/docs/sharing) publishes every page in the artboard. Visitors can pan, zoom, inspect layers, and copy code without signing in, but cannot comment or edit parameters.
