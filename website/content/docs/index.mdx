**案间（Anjian）** 是给你和 AI Agent 一起用的作品工作台。

写代码或做设计时，光靠聊天框很难看清效果。案间把 Agent 生成的**画板、文档、HTML 页面**（以及白板、幻灯片、分镜）直接摆在浏览器里——你在具体位置点一下写批注，再让 Agent 读评论、改代码、推新版，不用反复截图和口述位置。

## 选一条你的上手路径 [#从你的场景开始]

| 你现在的情况 | 第一步 |
| --- | --- |
| **已有账号或收到朋友的邀请链接** | 点右上角「进入工作台」登录，再按 [设备与 CLI](/zh/docs/remote-cli) 连接本地 Agent |
| **想先在自己电脑上试一下** | 按 [在本机使用](/zh/docs/local) 下载安装包或源码构建，然后 [创建第一份作品](/zh/docs/first-artifact) |
| **想体验白板、幻灯片、分镜与文档评审** | 直接看 [新功能上手指南](/zh/docs/review-workflows) |
| **想部署到自己的服务器长期用** | 按 [部署自己的实例](/zh/docs/self-hosting) 启动 Docker 服务，配置 HTTPS 和 GitHub 登录 |

## 核心功能一览 [#全部功能]

- **[画板](/zh/docs/artboards)**：多页设计方案并排对比，支持缩放、图层与样式检查、元素批注、方案投票、验收打回和交互原型。
- **[文档](/zh/docs/documents)**：富文本方案评审，支持划词评论、浏览器直接改字、引用其他作品、发起问答/批准，以及历史差异对比。
- **[HTML 预览](/zh/docs/html)**：在隔离沙盒里打开完整网页，直接点交互并把选区反馈发给 Agent。
- **[白板、幻灯片与分镜](/zh/docs/review-workflows)**：画流程图、放演示文稿、剪辑分镜导出 MP4，一套批注体验。
- **[接入 Agent](/zh/docs/agent)**：让 Claude Code、Codex、Pi、Antigravity、Copilot CLI 等宿主读写作品、拉取并回复批注。
- **[公开分享](/zh/docs/sharing)与[邀请朋友](/zh/docs/members)**：发一个免登录只读快照链接，或用 GitHub 邀请朋友拥有独立空间。
- **[作品库](/zh/docs/library)与[存储](/zh/docs/storage)**：按项目筛选、批量整理、30 天回收站，支持接入 S3 存储。

## 数据放在哪里？ [#数据在哪里]

- **本机模式**：作品保存在你项目的 `.anjian/artifacts/` 目录里，服务状态保存在 `~/.anjian/server/`。
- **自托管模式**：数据留在你自己的服务器上，本地和服务器通过 CLI 显式 `push` / `pull` 同步。

案间不连任何官方云服务，没有订阅，也不会自动下载上游包。来源与许可见 [开源与许可](/zh/docs/about)，真实协作案例见 [用画板批注改设计稿](/zh/use-cases)。
