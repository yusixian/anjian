案间（Anjian）把作品和讨论放在一起。你或 Agent 在项目里写文件，浏览器展示作品；你在具体位置留下批注，Agent 读取反馈后修改、上传，再回来核对结果。

## 全部功能

- **画板**：多页设计方案、平移缩放、图层与属性检查、位置批注、方案选择、可交互原型和参数调整。[阅读画板指南](/docs/artboards)
- **文档**：富文本阅读、浏览器改字、选文批注、代码与图表、历史差异对比。[阅读文档指南](/docs/documents)
- **HTML**：在隔离环境预览网页，试用作品中提供的交互和反馈控件。[阅读 HTML 指南](/docs/html)
- **批注与 Agent**：读取评论、回复、跟踪待处理事项，使用显式同步把修改传回作品。[接入 Agent](/docs/agent)
- **作品管理**：项目与类型筛选、搜索、多选、回收站和恢复。[管理作品](/docs/library)
- **分享与成员**：发布只读快照，或邀请指定 GitHub 账号获得独立空间。[了解区别](/docs/members)
- **存储**：共享额度、个人或共享 S3、校验后迁移、磁盘概览与备份。[管理存储](/docs/storage)

## 数据在哪里

本机作品保存在你指定项目的 `.anjian/artifacts/` 中。自托管作品保存在自己的服务器上，本地与服务器之间通过 CLI 显式上传和拉取。公开分享保存的是发布时的快照。

案间不依赖 Ryugi 官方云服务，没有官方账号、订阅或自动下载上游发行包。案间从 Ryugi 分叉并独立维护，来源和许可证见[开源与许可](/docs/about)。
