## 方式一：让 Agent 帮你建（推荐） [#用-agent-创建]

CLI 内置了完整的 Skill 指引，直接把下面这段复制给你的 Agent（把两处路径换成你的实际路径，完整接入见 [批注与 Agent](/zh/docs/agent)）：

```text title="复制给 Agent · 本机 HTML 示例"
请在本机模式创建一份名为 hello 的最小 HTML 作品。
CLI：node /绝对路径/anjian/artifacts/dist/cli.cjs
作品项目：/绝对路径/你的项目
先用上述 CLI 执行：
skills get artifacts
skills get artifacts --reference html.md
按指引创建作品，运行 check，并把预览链接发给我。
```

如果是远程服务器，请让它再读 `skills get artifacts --reference remote.md`，并按 [设备与 CLI](/zh/docs/remote-cli) 核验绑定。

## 方式二：手动建一个最小 HTML 试试 [#手动创建-html]

确认本机服务已启动（见 [在本机使用](/zh/docs/local)），在作品项目里新建：

```text
.anjian/artifacts/html/hello/index.html
```

写入下面的内容：

```html title="index.html"
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>我的第一份作品</title>
  </head>
  <body>
    <h1>你好，案间</h1>
    <p>这是保存在自己项目里的页面。</p>
  </body>
</html>
```

跑一次检查，然后刷新浏览器作品库就能看到：

```bash title="终端"
anjian check --project-dir /绝对路径/你的项目 --artifact html/hello --json
```

> 远程模式下保存后记得执行 `anjian push --artifact html/hello`，详见 [设备与 CLI](/zh/docs/remote-cli)。

## 三种作品怎么选？ [#选择作品类型]

| 类型目录           | 入口文件                 | 适合放什么                         |
| ------------------ | ------------------------ | ---------------------------------- |
| `html/<名称>/`     | `index.html`             | 单个页面、组件演示、可点击原型     |
| `document/<名称>/` | `doc.xml` + `assets/`    | 技术方案、PRD、评审文档、图表      |
| `artboard/<名称>/` | `canvas.json` + `pages/` | 多页面设计稿、方案对比、多状态展示 |

每份作品单独一个目录，资源放同目录用相对路径引用；评论、历史和 `.state` 由案间维护，无需手改。
