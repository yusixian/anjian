---
title: 设备与 CLI
description: 用浏览器配对授权，把本地项目和自托管案间连起来，通过 HTTPS 同步作品。
---

如果你使用的是自托管实例（例如 `https://anjian.cosine.ren`），本地 Agent 通过 CLI 同步作品和评论，每台电脑只需配对一次。

> 下文 `anjian` 指你的 CLI 包装器、安装包入口，或 `node /绝对路径/anjian/artifacts/dist/cli.cjs`（详见 [批注与 Agent](/zh/docs/agent)）。

## 1. 先检查指引与绑定状态 [#安装与授权]

先确认当前项目是不是已经连好了（已绑定直接复用，不需要重新配对）：

```bash title="终端 · 发现指引并检查状态"
anjian --help
anjian skills list
anjian skills get artifacts
anjian skills get artifacts --reference remote.md
anjian remote status --json
```

## 2. 首次配对设备 [#首次配对]

仅在未授权、凭证过期或被撤销时运行：

```bash title="终端 · 发起配对"
anjian login https://你的案间域名 --name "我的 MacBook"
```

浏览器会自动打开配对页（无桌面环境可加 `--no-open`，手动打开终端输出的链接）：

1. 还没登录的话先登录工作台。
2. 核对**设备名称**和 **12 位配对码**。
3. 勾选允许这台设备访问的项目，点「批准连接」。

配对码 10 分钟有效，设备凭证 90 天有效。

## 3. 绑定本地项目目录 [#绑定作品项目]

进入你的本地项目目录执行：

```bash title="终端 · 绑定项目"
anjian link
anjian remote status --json
```

账号下有多个项目时，按提示用 `anjian link --project <项目ID>` 指定即可。

## 4. 推送与拉取作品 [#上传与拉取]

```bash title="终端"
anjian push --artifact document/plan  # 上传本地改动
anjian check --artifact document/plan # 检查格式与资源
anjian pull --artifact document/plan  # 拉取服务器最新版本
```

- **只同步作品源文件**：传输 `.anjian/artifacts/<类型>/<名称>/` 下的文件，不含评论、历史、隐藏文件或符号链接。上限 1,000 个文件、32 MiB。
- **不会悄悄覆盖**：发生冲突时 `push` / `pull` 都会拦截。想保留本地副本再拉取，用 `anjian pull --artifact <id> --backup-local`，之后手动对比合并。

## 5. 查看与撤销设备 [#查看与撤销设备]

在工作台左侧「设备与 CLI」可随时撤销任意设备（只取消访问权限，不删作品和评论）。在终端退出或解绑：

```bash title="终端"
anjian logout https://你的案间域名
anjian unlink
```

客户端凭证保存在 `~/.anjian/client/`（可用 `ANJIAN_CLIENT_HOME` 自定义）。

## 常见连接报错 [#连接问题]

公网实例必须使用 `https://` 且与服务配置的域名一致；401 重新 `login`，403 检查授权项目，429 稍等几秒重试。
