Anjian brings artifacts and discussions together. You or your Agent write files in a project, and the browser displays the result. Leave comments at specific locations; the Agent reads your feedback, edits and uploads the artifact, then you return to check the result.

## Features

- **Artboards**: multi-page designs, pan and zoom, layer and property inspection, location-based comments, option selection, interactive prototypes, and adjustable parameters. [Artboard guide](/docs/artboards)
- **Documents**: rich text, browser editing, text-anchored comments, code and diagrams, and history comparisons. [Document guide](/docs/documents)
- **HTML**: preview web pages in an isolated environment and try the interactions and feedback controls provided by the artifact. [HTML guide](/docs/html)
- **Comments and Agents**: read and reply to comments, track outstanding work, and explicitly sync changes back to artifacts. [Connect an Agent](/docs/agent)
- **Artifact management**: filter by project and type, search, select multiple artifacts, and use the trash and restore features. [Manage artifacts](/docs/library)
- **Sharing and members**: publish read-only snapshots or invite a specific GitHub account to an independent space. [Understand the difference](/docs/members)
- **Storage**: shared quotas, personal or shared S3, verified migration, disk usage, and backups. [Manage storage](/docs/storage)

## Where your data lives

Local artifacts live in `.anjian/artifacts/` inside your chosen project. Self-hosted artifacts live on your server, with explicit CLI uploads and downloads between your computer and the server. Public shares contain a snapshot taken when published.

Anjian does not rely on Ryugi's official cloud, official accounts, subscriptions, or automatic downloads of upstream releases. It is an independently maintained fork of Ryugi. See [source and licensing](/docs/about).
