---
title: 用画板批注改设计稿
description: 真实案例：我们怎么用案间画板批注，直接让 Agent 修改这个文档站的设计。
---

你正在看的这个文档站，本身就是用案间做出来的：先让 Agent 出一版设计画板，我们在浏览器里圈出要改的地方，再让它拉取评论逐条改完。

## 1. 在画板上指出要改的地方 [#1-在画板上指出问题]

打开设计稿，按 `C` 切到评论工具，直接在有问题的元素上留意见——搜索图标太小、文字太啰嗦、排版要调整。评论钉在具体位置上，Agent 读取时能拿到文字和对应节点。

![案间画板展示文档站的深浅色设计稿，右侧四条评论分别指出搜索图标、图标大小、多余文字和首页排版问题。](/use-cases/artboard-comments.png)

## 2. 把链接丢回会话，让 Agent 改 [#2-回到会话让-agent-读取并修改]

把作品链接发给已接入案间的 Agent，说一句「看看我的所有评论，修复一下」。Agent 会拉取批注、改源文件、推送新版，再在原评论里回复改了什么。

![在会话中发送画板链接并要求处理评论，Agent 开始通过 CLI 读取全部批注。](/use-cases/agent-feedback.png)

## 3. 回到画板核对并收尾 [#3-查看新版再决定下一步]

刷新作品看新版效果，不满意继续留批注，满意了就把对应评论标为「已解决」。
