## Why is my library empty?

1. Make sure `--project-dir` points to your actual project folder (not the Anjian source repo).
2. Check that files live in `.anjian/artifacts/<type>/<id>/` with the right entry file (`index.html`, `doc.xml`, or `canvas.json`).
3. In remote mode, remember to run `anjian push` after saving local files.

## Why can't my friend open the link? [#why-cant-my-friend-open-the-link]

Make sure you didn't send a `localhost` URL, your self-hosted server is up over HTTPS, and the share link hasn't expired or been turned off. Use **Share** for read-only viewing—never share your admin access key.

## I edited the artifact—why didn't the public link update? [#why-is-the-public-page-out-of-date]

Public links are static snapshots. Open **Share** and click **Update shared version** to publish your latest edits.

## Why didn't my Agent start working after I left a comment? [#why-didnt-a-comment-automatically-start-my-agent]

In remote mode, comments are saved without auto-waking chat sessions—send the link to your Agent (or wire up `anjian watch --json`). For live local subscriptions, see [Review Workflows](/en/docs/review-workflows).

## How do I fix a `push` or `pull` conflict? [#what-should-i-do-about-a-push-or-pull-conflict]

Both local and remote copies changed. Pull with a local backup and merge manually:

```bash
anjian pull --artifact < type > / < id > --backup-local
```

## A document says "Not synced"—what should I do? [#what-if-a-document-says-it-is-unsaved]

**Don't refresh or close the tab.** Check your network or storage quota; once resolved, the page saves automatically.

## Why can't I push a deleted artifact ID? [#why-cant-i-push-a-deleted-artifact-again]

The server blocks deleted IDs to avoid accidental resurrection. Restore it from **Trash** first, or pick a new ID if it was permanently deleted.

## Can I delete server files after turning on S3? [#can-i-delete-server-files-after-setting-up-s3]

No. Serving uses the server cache, and metadata (members, invites, credentials, bindings) lives on the server. See [Storage & Backups](/en/docs/storage).

## How do I report a bug? [#how-do-i-report-a-problem]

Open an issue on [GitHub Issues](https://github.com/yusixian/anjian/issues) with steps to reproduce and error output. **Strip any access keys, device tokens, or signed URLs first.**
