<Notice title="Before you start">
  Use a package from Anjian's GitHub Releases or build from this repository. The source build below
  requires Git, Node.js, and pnpm.

## Install and start

On macOS, [download the archive for your Mac](https://github.com/yusixian/anjian/releases), verify its SHA-256 checksum, and extract it. Run the included `anjian` command to start your project. See [macOS installation and offline updates](https://github.com/yusixian/anjian/blob/main/docs/install.md).

<Steps>
<Step title="Get the source and build">
Clone the repository, then install the locked dependencies in the application directory.

```bash title="Terminal · Get the source"
git clone https://github.com/yusixian/anjian.git
cd anjian/artifacts
pnpm install --frozen-lockfile
pnpm build
```

</Step>
<Step title="Start your artifact project">
Replace the path below with your actual artifact project directory and keep this terminal running.

```bash title="Terminal · artifacts directory"
node dist/cli.cjs start \
  --project-dir /absolute/path/to/artifact-project \
  --no-open --foreground
```

</Step>
<Step title="Open your browser">
Open the complete URL printed in the terminal. Do not invent a port or drop the access parameters. If your library is empty, continue with [your first artifact](/docs/first-artifact).
</Step>
</Steps>

## Linux user service

After building from source on Linux with systemd, use your own user manager to start the local Hub at login. Install the service and start it separately. If you started the same Hub manually, use `anjian stop` when it is safe to stop it.

```bash
node dist/cli.cjs service install --project-dir /absolute/path/to/artifact-project
node dist/cli.cjs service start
node dist/cli.cjs service status --json
```

Run `node dist/cli.cjs start --project-dir /absolute/path/to/artifact-project --no-open` to print the running Hub's link. Systemd retries after an unexpected Hub exit. Use `service stop` to stop the service, or `service uninstall` to stop it and remove login startup. Both preserve artifacts and local Hub state. Uninstall the unit before changing the project or moving the Anjian installation, then install it again. For containers, follow the [self-hosting guide](/docs/self-hosting).

## Artifacts and service state

Artifacts live in the project's `.anjian/artifacts/`; service state defaults to `~/.anjian/server/`. Exiting the foreground process does not delete artifacts. Start with the same project directory next time to continue.

A local service can register multiple projects. Stopping a shared service affects every project it serves; check that no other project is using it first.

## Open from another device

`localhost` means the device opening the link, so you cannot send that address directly to another computer or phone. For remote access, set up [self-hosting](/docs/self-hosting), then create a [public share](/docs/sharing) or [member invitation](/docs/members). The service must stay running and be reachable from the other device.

## Update Anjian

Back up your artifacts and service state. To update a packaged installation, download the new archive and checksum, extract it offline, and start from the new folder. If you built from source, rebuild the new version and restart the service.
