## Option 1: Download a release package (fastest) [#install-and-start]

Grab the archive and `.sha256` file from [GitHub Releases](https://github.com/yusixian/anjian/releases) (Node.js is bundled inside—just verify, unpack, and run):

- **macOS**: `darwin-arm64` for Apple Silicon, `darwin-x64` for Intel (`shasum -a 256 -c <file>.sha256`).
- **Linux (glibc)**: `linux-x64` for `x86_64`, `linux-arm64` for `aarch64` (`sha256sum -c <file>.sha256`).

Then run `./anjian start --project-dir /abs/path/to/your-project --no-open --foreground`. See [docs/install.md](https://github.com/yusixian/anjian/blob/main/docs/install.md) for details.

## Option 2: Build from source [#build-from-source]

Requires Git, Node.js (22 recommended), and pnpm:

<Steps>
<Step title="Clone and build">

```bash title="Terminal"
git clone https://github.com/yusixian/anjian.git
cd anjian/artifacts
pnpm install --frozen-lockfile
pnpm build
```

Optional alias so every `anjian` command in these docs works out of the box:

```bash title="Add to ~/.zshrc or ~/.bashrc"
alias anjian="node /path/to/anjian/artifacts/dist/cli.cjs"
```

</Step>
<Step title="Start for your project">

Point `--project-dir` to any folder where you want to store artifacts:

```bash title="Terminal"
anjian start --project-dir /abs/path/to/your-project --no-open --foreground
```

</Step>
<Step title="Open in your browser">

Open the full URL printed in the terminal (including its access query parameter). Head to [Create Your First Artifact](/en/docs/first-artifact) next.

</Step>
</Steps>

## Linux user service (systemd) [#linux-user-service]

On systemd-based Linux machines, you can register the local Hub as a user service (stop any manually started Hub with `anjian stop` first):

```bash
./anjian service install --project-dir /abs/path/to/your-project
./anjian service start
./anjian service status --json
```

Use `service stop` to pause or `service uninstall` to remove autostart—your artifacts stay intact.

## Where files live [#artifacts-and-service-state]

- **Artifacts**: `<your-project>/.anjian/artifacts/`
- **Server state & logs**: `~/.anjian/server/` (including `hub-events.jsonl`)

Stopping the process never deletes artifacts.

## Need access from another device? [#open-from-another-device]

`localhost` only works on the machine running it. To open links on your phone or share with friends, deploy over HTTPS with [Self-Hosting](/en/docs/self-hosting).

## Updating [#update-anjian]

- **Release packages**: Download and unpack the new archive from Releases.
- **Source builds**: Run `git pull`, rebuild in `artifacts/` with `pnpm install --frozen-lockfile && pnpm build`, and restart.
