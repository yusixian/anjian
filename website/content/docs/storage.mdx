title: 存储与备份

## 共享容量额度 [#共享额度]

管理员在「存储设置 → 实例共享」设好总容量预算，再按需给每位成员分配上限。用量包含作品、历史、协作数据、回收站和分享快照；额度满时暂停保存，文档提示未保存时先别刷新页面，腾出空间或调高额度后会自动重试。

## 配置共享或个人 S3 [#配置共享或个人-s3]

管理员可配置共享 S3，成员可在「我的 S3」绑自己的 S3（启用后不占实例共享额度）：

1. 填写公网 HTTPS Endpoint、Bucket、Region、可选前缀和专用凭据（多数自托管 S3 需勾选路径式寻址）。不支持内网地址或自签证书。
2. 点「保存配置」→「测试连接」（写入、校验并删除测试对象）。保存与测试不会移动文件。

## 迁移与启用 [#迁移与启用]

按顺序点 **「准备迁移」** → **「复制并校验」** → 勾选确认后 **「启用 S3」**。启用后显示「S3（服务器缓存）」，文件通过服务器缓存读写并同步到 S3，服务器原文件会继续保留。

## 失败与恢复 [#失败与恢复]

同步失败时本地修改不会丢，点「重试同步」即可。重启后如提示待恢复，确认服务器原文件完整再按页面指引校验恢复。

## 服务器磁盘 [#服务器磁盘]

管理员在「实例共享」页可查看数据所在磁盘的总量、已用和可用空间（含系统及其他程序占用，每 60 秒刷新）。

## 备份范围 [#备份范围]

成员、邀请、加密凭据和存储绑定等元数据仍在服务器本地，配置 S3 不会自动备份它们。Docker 部署请定期备份整个 `/data` 卷；本机模式请备份项目的 `.anjian/` 与 `~/.anjian/server/`。
