title: 存储与备份

## 共享额度

管理员在「存储设置 → 实例共享」设置总容量，并为成员分配个人上限。页面用量包含受管理的作品、历史、协作状态、回收站及分享快照，不等于整个磁盘占用或 S3 服务商余额。

额度不足时新增保存可能被拒绝。文档提示未保存时不要刷新或关闭，先释放资源或增加额度，再确认保存完成。

## 配置共享或个人 S3

管理员配置实例共享存储；成员可在「我的 S3」配置自己的存储。填写 Endpoint、Bucket、Region、对象前缀和专用凭据；需要路径式寻址的服务勾选对应选项。

使用公开 HTTPS 地址，不支持私网 endpoint 或自签证书。保存后凭据不回显，留空可保留已有凭据。配置改变后重新保存和测试。

连接测试会写入一个小对象、读回校验并删除。清理失败时按提示检查测试对象。保存成功不代表连接成功，连接成功也不会自动切换存储。

## 迁移与启用

1. 保存配置并通过连接测试。
2. 点击「准备迁移」，列出来源；准备期间相关作品可能暂时暂停访问。
3. 点击「复制并校验」，等待完成。失败时当前存储不切换，可继续复制或重新准备。
4. 校验通过后，勾选「启用此 S3，并保留服务器原文件」，再启用。源文件已变化时需要重新准备。

启用后显示「S3（服务器缓存）」，作品仍通过服务器缓存提供访问，并同步到所选 S3。个人 S3 启用后该空间不再消耗实例共享额度。原文件不会自动删除。

## 失败与恢复

同步失败时本地修改保留，可恢复连接后重试。重启后如出现待恢复提示，先检查服务器保留文件，再按页面确认以保留文件为准并校验恢复。不要用空目录替代缺失来源，或删除绑定记录来绕过恢复。

## 服务器磁盘

管理员的实例共享页显示数据所在文件系统的总量、已用与进程可用空间，跨多个磁盘时分别显示。同一文件系统只统计一次。数据包含其他程序与系统占用，区别于应用额度。

页面每 60 秒刷新，后台标签暂停，失败保留上次读数并标记过期。提醒不会自动删除或迁移文件。

## 备份范围

S3 中的保留对象、服务器缓存、临时空间仍可能占用额外容量。应用额度不是服务商硬配额。

成员、邀请、加密凭据、配置和存储绑定等元数据仍在服务器上；配置 S3 不会自动备份这些数据。标准 Compose 部署备份整个 `/data` 卷；本地项目保留整个 `.anjian/`，另备份服务状态。实际验证恢复后才能依赖备份。
