## 浏览与检查

画板支持多页分区，顶栏切换页面，工具栏支持「适合画布」和「100%」。桌面快捷键：

- `V`：选择元素
- `H` 或按住空格：抓手拖动画布
- `C`：添加评论

选中元素后，右侧检查器展示图层树、尺寸、样式和实时 HTML/CSS。检查器里的样式修改仅做预览，刷新后恢复——要持久改动，留条批注让 Agent 改源文件即可。

## 批注、选方案与验收 [#批注与方案选择]

- **定点批注**：可锚定到元素、画板坐标或空白画布。写清目标效果（如「把这个按钮与标题左对齐」），Agent 改起来更准。
- **方案选择与验收**：Agent 可把多个方案组成选择组让你投票提交，或组成验收组让你逐项通过/打回。

## 交互原型与参数 [#交互与参数]

默认画板为静态页面；如果板块声明了交互或参数，可点「播放」试用交互、点「参数」实时调控件。图片和视频也能放进画板；手机端支持切页和检查属性。

## 给 Agent 的文件约定

画板位于 `.anjian/artifacts/artboard/<id>/`（`canvas.json` + `pages/`）。让 Agent 用 CLI 读取完整指引（配置见 [批注与 Agent](/zh/docs/agent)）：

```bash
anjian skills get artifacts
anjian skills get artifacts --reference artboard.md
anjian skills get artifacts --reference artboard-prototype.md
```

## 公开分享 [#公开画板]

[公开分享](/zh/docs/sharing) 会打包整个画板的全部页面。访客免登录即可缩放、查图层和复制代码，但不能评论或改参数。
