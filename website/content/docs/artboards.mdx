title: 画板
description: 把多个页面和方案放在同一张画布里，让讨论落在具体位置。

## 浏览与检查

画板支持多个页面。通过页名切换分区，用缩放、抓手和平移查看不同设计。工具栏提供适合画布和 100% 缩放；桌面可使用 `V` 选择、`H` 抓手或按住空格、`C` 评论。

选择元素后，在检查器中查看图层、尺寸、样式属性和代码。检查器里的调整属于预览反馈；需要 Agent 修改源文件并重新上传，才能成为持久的作品内容。

打开可编辑画板，点「调整布局」，再拖动卡片、标题或便签上的把手。也可以聚焦把手后按方向键。点「完成布局调整」退出。Hub 会保留同一页同一对象的人工位置，Agent 更新作品内容后也会沿用。

点「选择画布对象」，再点卡片、标题或便签上的选择按钮，即可选中多个对象。随后告诉 Agent 想改什么。点「清除对象选区」或切换页面会清除该页选区。

同一页的板块可以用箭头串成流程。让 Agent 为起点、终点和动作填写连线，例如从「登录」指向「工作台」，标注「继续」。移动板块后，箭头会跟随新位置。

## 批注与方案选择

评论可以锚定到元素、画板中的位置或空白画布。描述期望的变化，例如「这个按钮与标题对齐」，比只写「这里不对」更容易执行。

Agent 可将多个设计组织为选择组，让你选中方案并提交；也可提供验收组，由你通过或打回。不是每张画板都会显示这些入口，它们取决于作品的声明。

## 交互与参数

默认画板为静态设计。标记为可交互的板块才有播放入口，可在播放状态试用页面，之后停止或重播。声明了可调参数的板块可通过参数面板调整内容。不要把静态设计稿当成已实现功能。

支持的板块还可以展开查看或下载；图片、视频也能作为画板内容。手机使用页面切换与检查器入口查看细节。

## 给 Agent 的文件约定

画板目录是 `.anjian/artifacts/artboard/<id>/`。`canvas.json` 声明页面、板块、分组、注释与位置；页面资源放在 `pages/` 下。Agent 应先执行 `anjian skills get artifacts --reference artboard.md`，交互稿再执行 `anjian skills get artifacts --reference artboard-prototype.md`。

修改现有画板时保留原 ID、页面和批注上下文。远程作品先拉取，再编辑、上传和检查。

## 公开画板

[公开分享](/docs/sharing)包含整个画板的全部页面。访客能浏览、缩放、检查图层和复制代码，但不能修改属性、调整参数、评论或管理作品。

这里的 `anjian` 指构建后的 CLI 或已有包装器；可执行入口与内置 Skill 的发现方式见[批注与 Agent](/docs/agent)。
