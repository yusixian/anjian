---
title: 部署自己的实例
description: 用 Docker Compose 或 Dokploy 部署自己的案间，通过 HTTPS 随时访问。
---

## 准备条件 [#部署前准备]

- 一台支持 Docker Compose 的服务器和持久化磁盘
- 两个 HTTPS 域名（主站 + 画板隔离预览）

## 两个来源 [#两个来源]

| 用途 | 容器端口 | 环境变量 | 示例 |
| --- | --- | --- | --- |
| 主站（工作台、文档、评论、WebSocket） | `27319` | `ANJIAN_PUBLIC_ORIGIN` | `https://anjian.example.com` |
| 画板隔离预览 | `27329` | `ANJIAN_BOARD_ORIGIN` | `https://preview.example.net` |

> 两个环境变量只填 `协议://域名`（不带末尾路径）。主站反向代理需开启 WebSocket 支持。

## Docker Compose 启动 [#docker-compose]

```bash title="终端 · 仓库根目录"
export ANJIAN_PUBLIC_ORIGIN=https://anjian.example.com
export ANJIAN_BOARD_ORIGIN=https://preview.example.net
docker compose up --build -d
docker compose logs anjian
```

默认端口绑定在回环地址，用 Nginx / Caddy / Traefik 将两个 HTTPS 域名分别转发到 `27319` 和 `27329`。数据持久化在 `anjian-data` 卷（`/data/project` 与 `/data/server`），请妥善保存启动日志里的管理员访问密钥。

## Dokploy 部署 [#dokploy]

1. 新建基于本仓库的 Compose 应用（构建路径 `/`，Compose 文件 `compose.yaml`）。
2. 在环境变量中填入 `ANJIAN_PUBLIC_ORIGIN` 和 `ANJIAN_BOARD_ORIGIN`。
3. 为 `anjian` 服务绑定主站域名（`27319`）和预览域名（`27329`）并开启 HTTPS，点击部署。

## 开启 GitHub 登录与邀请（可选） [#github-登录与邀请]

在 GitHub 创建 OAuth App（Homepage URL 填主站地址，回调填 `https://主站域名/auth/github/callback`），在部署环境变量中添加：

```dotenv title="部署环境变量（不要提交到仓库）"
ANJIAN_GITHUB_CLIENT_ID=<OAuth Client ID>
ANJIAN_GITHUB_CLIENT_SECRET=<OAuth Client Secret>
ANJIAN_GITHUB_OWNER_ID=<管理员的 GitHub 数字 ID>
```

三项都留空时使用管理员访问密钥登录；只填部分会拒绝启动。开启后仅管理员和受邀成员可登录，管理员密钥仍可作为备用入口。

## 部署后检查 [#部署后检查]

打开主站确认登录、画板/HTML 预览和评论实时同步正常，并用本地 CLI 跑通一次 `login` → `link` → `push`，重启容器后确认数据保留即可。
