## Create a public link

Open any artboard, document, HTML page, whiteboard, or slide deck, click **Share**, pick an expiration (`1 day`, `7 days`, `30 days`, or `No expiry`), and click **Create public link**. For review documents, you can also include snapshots of referenced artifacts in the same project.

Sharing is off by default and publishes a **static snapshot**:

- Artboards include **all pages**—click **Preview guest view** before sharing.
- Comments, revision history, and other private artifacts are never included.

## What visitors can do

Anyone with the link can view without signing in: artboards support page switching, pan/zoom, layer inspection, and code copying; documents and HTML render full content and local scripts. Visitors cannot comment, change parameters, or browse other artifacts.

> Read-only links can still be screenshotted or forwarded—check for sensitive info first.

## Updating, resetting & turning off [#update-or-revoke-a-share]

| Action | Result |
| --- | --- |
| **Update shared version** | Publishes latest edits to the same link and expiry |
| **Reset link** | Invalidates the old URL and generates a new one; content stays the same |
| **Turn off sharing** | Stops public access; your artifact and comments stay untouched |
| **Move to trash** | Turns off sharing automatically; restoring doesn't re-publish |

## Limits [#network-and-capacity]

- `localhost` links only work on your machine—set up [Self-Hosting](/en/docs/self-hosting) first.
- Up to **1,000 files and 32 MiB** per snapshot; updating briefly holds both old and new snapshots.
- Public pages run in a sandbox that blocks external API calls, form submissions, and popups.
