title: Inviting Friends
description: Give friends their own isolated workspace on your self-hosted instance using GitHub sign-in.

## Public link vs. inviting a friend [#choose-how-to-share]

| Goal | Use | Access |
| --- | --- | --- |
| Show one artifact | [Public sharing](/en/docs/sharing) | Read-only snapshot, no sign-in |
| Let a friend create and manage their own work | **Invite a friend** | GitHub sign-in with separate projects, devices, and storage |

<Notice title="Prerequisites">
  Only the instance admin can send invitations, and GitHub sign-in must be configured first (see
  [Self-Hosting](/en/docs/self-hosting)). Never share your admin access key.
</Notice>

## For admins: send an invite [#administrator-create-an-invitation]

<Steps>
  <Step title="Set shared capacity">
    Go to **Storage → Instance shared** and set the total shared quota budget.
  </Step>
  <Step title="Create an invite link">
    Open **Members**, click **Invite a friend**, enter their GitHub username, and assign a shared
    quota (`0` means no shared quota—they can still connect their own S3).
  </Step>
  <Step title="Share the link">
    The link is **shown only once**, bound to that GitHub account, valid for 7 days, and single-use.
    If it expires or gets lost, revoke it and create a new one.
  </Step>
</Steps>

## For friends: accept and start [#friend-accept-and-start]

1. Open the invite link and sign in with the invited GitHub account to land in your own workspace.
2. Pair your local Agent in [Devices & CLI](/en/docs/remote-cli), and optionally bind your own bucket under **Storage → My S3**.

## Managing members [#adjust-quotas-and-suspend-access]

Admins can update quotas, revoke pending invites, or suspend a member at any time. Suspending ends active sessions and CLI tokens while keeping files intact; once restored, the member simply signs in and pairs again.

## Invite link not working? [#invitation-problems]

Check whether the link expired (7 days), was already accepted or revoked, or if you signed in with a different GitHub account. Ask the admin to send a fresh invite.
