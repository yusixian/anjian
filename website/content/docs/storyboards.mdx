## 剪辑第一段 [#剪辑第一段]

1. 在作品库选中项目，点「新建分镜」。
2. 在素材库导入画面或音频，用素材旁的「加入时间线」按钮把它放到对应轨道。
3. 选中片段，打开「属性」。用「时间线起点」决定片段在成片里的位置，用「素材入点」跳过源素材开头，再设置「时长」。

用鼠标点击监视器的视频画面可播放或暂停，之后按空格切换播放，按左右键定位五秒。触屏可用播放器的播放按钮和进度条。

## 逐行旁白 [#逐行旁白]

本机 macOS 版案间从 v0.18.21 起可用系统语音生成旁白。启动案间前，把 FFmpeg 加到终端的 PATH，并确保系统安装了所需的普通话或美式英语语音。

1. 在分镜的素材库打开「旁白」，点「添加旁白行」。
2. 填写原文并选择语音语言。可在「发音词表」录入原词和替代读法。「单行读音」填写整行实际要读的文字，优先于词表。
3. 点「生成试听」，播放试听音频，再点「加入音轨」。关闭旁白窗口后，可在「属性」调整音频片段的起点。
4. 用顶部的「保存」保存脚本和音轨。要替换旧旁白，生成新音频并加入音轨，再移除旧片段，将新片段调到原位置。

录制或生成好的 WAV、MP3、M4A 也可以从「导入素材」加到音轨。脚本和发音词表保存在当前分镜里。

## 生成与下载 [#生成与下载]

确保终端可找到 `ffmpeg` 和 `ffprobe`。点「保存并生成成片」或「生成成片」，在监视器切到「成片预览」核对画面与声音，再点「下载 MP4」。

先[接入 Agent](/zh/docs/agent)，再让它读取分镜指引：

```bash
anjian skills get artifacts --reference storyboard.md
```
