## 阅读与直接改字 [#阅读与编辑]

文档以富文本呈现，支持标题、表格、代码块、图片、公式、Mermaid 图表、作品引用和问答/批准卡片，左侧目录方便跳转。

点「改字」可直接在浏览器修改文稿。如果提示「未同步」或「存储额度已满」，先别刷新或关闭页面，等网络恢复或腾出空间后会自动保存。

## 划词批注 [#在文字上批注]

选中文字或段落即可评论，评论跟随对应位置显示在右侧栏。原段落被删时标记「锚点已失效」，讨论记录仍会保留。

## 历史对比 [#历史对比]

点「历史」任选两个时间点对比新增、删除和修改，支持「仅看变更」和逐处跳转。对比期间正文只读；媒体文件不做历史归档。

## 重跑验收检查 [#重跑验收检查]

包含验收报告的文档支持查看每项检查的命令和原始输出；内容更新后可让 Agent 重新跑验证并更新报告（详见 [新功能上手指南](/zh/docs/review-workflows)）。

## 给 Agent 的文件约定 [#文档源文件]

文档位于 `.anjian/artifacts/document/<id>/`（`doc.xml` LiteXML + `assets/`）。让 Agent 用 CLI 读取完整指引（配置见 [批注与 Agent](/zh/docs/agent)），编辑前先拉取最新内容并保留已有块 ID：

```bash
anjian skills get artifacts
anjian skills get artifacts --reference document.md
```
