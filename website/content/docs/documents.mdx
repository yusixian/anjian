## 阅读与编辑

文档以富文本呈现，支持标题、列表、表格、代码、图片、公式、Mermaid 图、图表、步骤和嵌入的动态内容。具体内容由作品提供。目录帮助定位章节。

有权限时可在浏览器使用「改字」编辑文本。Agent 也可以修改源文件；保存和协作状态由服务管理。看到「未同步」或「存储额度不足」时，不要刷新或关闭页面，先恢复连接或容量，并等待保存完成。

## 在文字上批注

选择文字或段落后添加评论。评论跟随对应内容，右侧可查看对话、回复与处理状态。原内容删除或大幅改动后，锚点可能失效，此时需要结合上下文确认位置。

让 Agent [读取批注并回复](/docs/agent)，完成后检查修改，再决定是否将评论标为已解决。

## 历史对比

打开「历史」，选择时间点或对比范围，查看新增、删除和修改；可只看变更并在各处差异之间跳转。对比期间正文为只读，有新内容时可以更新对比。

历史中的动态内容不运行；媒体资源没有完整历史归档，同一地址的图片可能已经更新。历史对比不能代替文件备份。

## 文档源文件

文档使用 `.anjian/artifacts/document/<id>/doc.xml`（LiteXML）与 `assets/`。这不是直接把 Markdown 文件改名成 XML。让 Agent 先执行 `anjian skills get artifacts --reference document.md`。

服务器会为块补齐 ID；编辑前重新读取文件，保留已有块 ID，避免批注丢失定位。不要从旧副本覆盖整份文档，也不要编辑服务器管理的 `comments.json`。

这里的 `anjian` 指构建后的 CLI 或已有包装器；可执行入口与内置 Skill 的发现方式见[批注与 Agent](/docs/agent)。
