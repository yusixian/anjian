---
title: Improve a docs site with artboard comments
description: Review a design, leave specific feedback, and ask an Agent to read comments and edit.
---

The design of this Anjian docs site is itself a use case: an Agent first created an artboard, the user pointed out changes in the browser, then returned to the conversation to ask the Agent to read comments and edit.

## 1. Point out problems on the artboard

Open the design and use the comment tool on specific elements or regions. For example: an unclear search icon, small header icons, redundant wording, or a home page presentation that needs adjustment. Comments remain beside the artifact, and the Agent can read both their content and location.

![The Anjian artboard shows light and dark docs designs. Four comments identify search visibility, icon size, redundant wording, and home page presentation.](/use-cases/artboard-comments.png)

## 2. Return to the conversation and request edits

Send the artifact link to an Agent connected to Anjian and ask it to “Read all my comments and fix the issues.” The Agent reads comments, pulls the artifact, edits, uploads and checks, then replies in the original threads.

![In a Lody conversation, the user requests an Anjian design, then sends an artboard link and asks the Agent to handle comments. The Agent starts reading all comments.](/use-cases/agent-feedback.png)

## 3. Review the new version and decide what comes next

Return to the same artifact to check the changes. Add more comments if adjustments are needed, and resolve them once satisfied. Comments and event watching do not wake an Agent automatically; in this example, the user returned to the conversation and requested action.

[View the public artifact for this example](https://anjian.cosine.ren/s/eTPVcN0J7yUd7-a1Gu9fv0FSsKRP3b7fUGoGqyfKfzA)

The public link is a read-only snapshot; visitors cannot add comments. The workflow above takes place in an authorized workspace. After editing the original, explicitly update the share to change the public version.
