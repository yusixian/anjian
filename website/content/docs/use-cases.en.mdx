title: Iterating on Designs with Artboard Comments
description: A real walkthrough of how we designed this docs site using Anjian artboard comments.
---

This docs site itself was designed inside Anjian: our Agent created an artboard, we pinned comments directly on the parts we wanted changed, and sent the link back to the Agent to iterate.

## 1. Pin feedback right on the artboard [#1-point-out-problems-on-the-artboard]

Open the design, press `C` to switch to the comment tool, and click the exact element—icon too small, copy too wordy, spacing off. Each comment stores both your note and its element anchor.

![An Anjian artboard showing light and dark docs designs with four pinned comments on icons, copy, and layout.](/use-cases/artboard-comments.png)

## 2. Send the link back to your Agent [#2-return-to-the-conversation-and-request-edits]

Drop the link in your Agent chat and say: "Read all my comments and fix them." The Agent pulls the threads via CLI, edits the source files, pushes the update, and replies to each comment.

![Chat session where the user sends the artboard link and the Agent pulls all comments via CLI.](/use-cases/agent-feedback.png)

## 3. Review and resolve [#3-review-the-new-version-and-decide-what-comes-next]

Reload the artboard to inspect the new version. Leave another round of comments if needed, or mark threads resolved once they look right.
