## 查找作品 [#查找作品]

作品库支持按**项目**和**类型**筛选、排序，以及按 `⌘K` / `Ctrl+K` 跨项目搜索。

## 批量整理 [#批量整理]

点「选择」进入多选模式：

- `Shift` + 点击：连续多选
- `⌘A` / `Ctrl+A`：全选当前筛选结果
- `Esc`：退出多选

选好后点「移入回收站」确认即可。

## 回收站与恢复 [#恢复与永久删除]

- **保留 30 天**：移入回收站的作品连同资源、批注和历史保留 30 天，到期自动清理。
- **随时恢复**：操作后可立即点「撤销」，或去左侧「回收站」恢复，原作品链接不变；点「永久删除」后无法找回。

## 本机与服务器副本 [#本机与服务器副本]

- **不影响本机文件**：自托管模式下只删除服务器副本，不会动你电脑上的原文件。
- **防误复活**：移入回收站会自动关闭公开分享；已删除的作品 ID 不能直接重新 `push`，想继续用请先恢复，永久删除后请换新 ID。
