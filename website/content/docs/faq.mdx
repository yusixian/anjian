## 作品库是空的？ [#作品库为什么是空的]

1. 确认 `--project-dir` 指向的是你的作品项目（不是案间源码仓库）。
2. 确认文件在 `.anjian/artifacts/<类型>/<名称>/` 下且入口文件正确（`index.html` / `doc.xml` / `canvas.json`）。
3. 远程模式下保存后记得跑一次 `anjian push`。

## 朋友打不开我发的链接？ [#朋友打不开我的链接]

检查发出去的是不是 `localhost`、自托管服务是否在线、HTTPS 是否正常，以及公开链接有没有过期或关闭。只想展示作品请用「分享」，不要发管理员访问密钥。

## 改完作品，公开链接里怎么没变？ [#为什么公开页面不是最新内容]

公开链接是静态快照。改完原稿后，点开「分享」→「更新分享」即可发布新版。

## 留了评论，Agent 怎么没自动干活？ [#为什么评论没有自动让-agent-工作]

远程模式下写评论只会保存不会自动唤醒会话，回到聊天窗口把链接发给 Agent 即可；本机模式可参考 [新功能上手指南](/zh/docs/review-workflows) 接入实时订阅，或搭配 `anjian watch --json` 写自己的脚本。

## `push` 或 `pull` 冲突怎么办？ [#push-或-pull-冲突怎么办]

说明本地和服务器都有改动。先备份本地副本再拉取，然后对比手动合并：

```bash
anjian pull --artifact < 类型 > / < 名称 > --backup-local
```

## 文档提示「未同步」怎么办？ [#文档显示未保存怎么办]

**不要刷新或关闭页面**。检查网络或存储额度，恢复后页面会自动重试保存。

## 删掉的作品为什么 `push` 不上去？ [#已删除的作品为什么不能再-push]

服务器会拦截已删除的作品 ID 防止误复活。想继续用请先去「回收站」恢复；永久删除后请换新 ID。

## 接了 S3 后能清空服务器文件吗？ [#配置-s3-后能删除服务器文件吗]

不能。读取依赖服务器缓存，成员、邀请、凭据和存储绑定等元数据也在服务器本地，详见 [存储与备份](/zh/docs/storage)。

## 怎么反馈 Bug？ [#如何反馈问题]

去 [GitHub Issues](https://github.com/yusixian/anjian/issues) 提交复现步骤和报错信息。**提交前记得去掉访问密钥、设备 token 和带密钥的链接。**
