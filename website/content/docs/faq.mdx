## 作品库为什么是空的？

确认 `--project-dir` 指向实际作品项目，文件在 `.anjian/artifacts/<类型>/<id>/` 内，并使用正确入口文件。远程模式还需要 `push`。源码仓库不会自动变成作品项目。

## 朋友打不开我的链接？

检查是否发了 `localhost` 地址、服务器是否仍在运行、HTTPS 与代理是否可达，以及公开链接是否过期或关闭。只想让朋友查看时创建公开分享，不要发送管理员访问密钥。

## 为什么公开页面不是最新内容？

公开分享是快照。修改草稿后，需要点击「更新分享」发布新版。公开快照也可能与工作台预览的网络能力不同，外部依赖会受到限制。

## 为什么评论没有自动让 Agent 工作？

评论保存与宿主任务调度是两个层次。回到 Agent 会话要求它读取评论；`watch` 只输出事件，自动处理需要另行配置宿主集成。

## push 或 pull 冲突怎么办？

停止同时编辑，读取远端状态并比较双方版本。本地有改动时不要强行覆盖；需要时显式使用 `pull --backup-local` 保留副本，再拉取、合并与上传。详见[设备与 CLI](/docs/remote-cli)。

## 文档显示未保存怎么办？

保持当前页面打开，检查网络和存储额度。恢复连接或增加容量后确认保存完成。刷新页面可能丢掉只保留在当前页面的修改。

## 已删除的作品为什么不能再 push？

服务器阻止旧 ID 自动复活。先到回收站恢复；永久删除后使用新的作品 ID 重新创建。

## 配置 S3 后能删除服务器文件吗？

不能把启用 S3 当成可以清空服务器。当前访问依赖缓存，元数据仍在服务器，保留文件还用于恢复。先按[存储与备份](/docs/storage)理解数据范围。

## 如何反馈问题？

在 [GitHub Issues](https://github.com/yusixian/anjian/issues) 提供步骤、预期与实际结果、版本和已脱敏的错误信息。不要提交访问密钥、设备 token 或包含凭据的完整链接。
