## Option 1: Let your Agent create it (recommended) [#create-with-an-agent]

The CLI bundles the full Skill instructions. Copy this prompt to your Agent (replace the two paths; see [Connect an Agent](/en/docs/agent) for full host setup):

```text title="Prompt for your Agent · Local HTML example"
Create a minimal HTML artifact named hello in local mode.
CLI: node /abs/path/to/anjian/artifacts/dist/cli.cjs
Project: /abs/path/to/your-project
First run with that CLI:
skills get artifacts
skills get artifacts --reference html.md
Follow the guide, run check, and send me the preview link.
```

For remote servers, also have it read `skills get artifacts --reference remote.md` and check its link in [Devices & CLI](/en/docs/remote-cli).

## Option 2: Create a minimal HTML page manually [#create-html-manually]

With your local server running ([Local Setup](/en/docs/local)), create:

```text
.anjian/artifacts/html/hello/index.html
```

Paste in a simple page:

```html title="index.html"
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>My First Artifact</title>
  </head>
  <body>
    <h1>Hello, Anjian</h1>
    <p>This page lives right inside your project.</p>
  </body>
</html>
```

Run a check and open your library in the browser:

```bash title="Terminal"
anjian check --project-dir /abs/path/to/your-project --artifact html/hello --json
```

> Using a remote server? Run `anjian push --artifact html/hello` after saving—see [Devices & CLI](/en/docs/remote-cli).

## Choosing an artifact type [#choose-an-artifact-type]

| Folder | Entry file | Best for |
| --- | --- | --- |
| `html/<id>/` | `index.html` | Single pages, component demos, clickable prototypes |
| `document/<id>/` | `doc.xml` + `assets/` | Specs, PRDs, review docs, diagrams |
| `artboard/<id>/` | `canvas.json` + `pages/` | Multi-screen designs, side-by-side options, state galleries |

Keep each artifact in its own folder with relative asset paths. Comments, history, and `.state` are managed by Anjian.
