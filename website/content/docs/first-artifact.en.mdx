title: Create your first artifact
description: Use a minimal HTML artifact to try saving, previewing, and checking your work.
---

## Create with an Agent

Ask your Agent to run `anjian skills get artifacts` using the built CLI. Provide the absolute CLI path, artifact project directory, and whether you are running locally or remotely. See [Comments and Agents](/docs/agent) for configuration. For example:

```text title="Copy to your Agent · Local HTML example"
Create a minimal HTML artifact named hello in local mode.
CLI: node /absolute/path/anjian/artifacts/dist/cli.cjs
Artifact project: /absolute/path/to/artifact-project
Reuse the project's configured CLI wrapper if one exists.
First run these with that CLI:
skills get artifacts
skills get artifacts --reference html.md
Follow the guidance, create the artifact, run check, and give me its link.
```

Replace both absolute paths before sending this prompt to your Agent. `anjian` is shorthand for that CLI, not an npm installation command. For a remote task, specify the server and project instead of local mode, read `skills get artifacts --reference remote.md`, then follow [Devices and CLI](/docs/remote-cli) to check and reuse the binding.

Having the repository on disk does not mean hosts such as Claude or Codex automatically load its Skill. Explicitly read it or install it using the host's supported mechanism.

## Create HTML manually

Start the service using the [local guide](/docs/local), then create this file in your artifact project:

```text title="Artifact directory"
.anjian/artifacts/html/hello/index.html
```

Write the complete page below. Keep filenames and directory type fields in English.

```html title="index.html"
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>My first artifact</title>
  </head>
  <body>
    <h1>Hello, Anjian</h1>
    <p>This page lives in my own project.</p>
  </body>
</html>
```

Run the check with the built CLI, using the same project path as at startup:

```bash title="Terminal · Built CLI"
node /absolute/path/anjian/artifacts/dist/cli.cjs check \
  --project-dir /absolute/path/to/artifact-project \
  --artifact html/hello --json
```

Open the page from the artifact library and confirm its content is visible. No check warnings does not prove the page's scripts have run; test interactions in the browser.

## Choose an artifact type

| Type | Source files | Good for |
| --- | --- | --- |
| `html` | `index.html` and assets | A page, component, or clickable prototype |
| `document` | `doc.xml`, `assets/` | Proposals, explanations, reviews, and diagrams |
| `artboard` | `canvas.json`, `pages/` | Multi-page designs, comparisons, and collections of states |

Give each artifact its own directory. Keep resources inside it and use relative URLs. The server maintains comments, history, and `.state`; do not edit these manually.

In remote mode, saving local files must be followed by `push`. See [Devices and CLI](/docs/remote-cli).
