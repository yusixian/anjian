## Project origins

Anjian is an independently maintained fork of [Innei/ryugi v1.51.2](https://github.com/Innei/ryugi/tree/v1.51.2), based on commit `6054b65ab9b2208a234a78632eb065cfeb3eb166`. It focuses on personal use, a Chinese-language experience, local operation, and deployment to your own server.

Thanks to Innei and the Ryugi contributors. The Ryugi workflow itself derives from [Superpowers](https://github.com/obra/superpowers), maintained by Jesse Vincent and contributors. The repository's `UPSTREAM.md` preserves the history.

## Maintenance and updates

Anjian does not connect to Ryugi's official cloud or automatically install upstream releases. Build updates from this project's source and deploy them yourself. Any later upstream code is reviewed individually for licensing.

[Visit Anjian's source repository](https://github.com/yusixian/anjian).
