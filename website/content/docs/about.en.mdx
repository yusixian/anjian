## Origin [#project-origins]

Anjian is forked from [Innei/ryugi v1.51.2](https://github.com/Innei/ryugi/tree/v1.51.2) (commit `6054b65ab9b2208a234a78632eb065cfeb3eb166`) and maintained independently for personal workflows, bilingual UX, local-first usage, and self-hosting.

Thanks to Innei and the Ryugi contributors, as well as Jesse Vincent and the [Superpowers](https://github.com/obra/superpowers) contributors. Full attribution lives in `UPSTREAM.md`.

## Licenses

| Scope | License |
| --- | --- |
| `artifacts/` app & build output | [AGPL-3.0-only](https://github.com/yusixian/anjian/blob/main/artifacts/LICENSE) |
| Skills, integrations & docs | [MIT License](https://github.com/yusixian/anjian/blob/main/LICENSE) |
| Third-party dependencies | Respective open-source licenses |

Renaming does not change inherited licenses. If you run a modified version as a network service for others, follow the AGPL-3.0 source-availability requirement.

## Independent maintenance [#maintenance-and-updates]

Anjian does not connect to Ryugi Cloud and does not auto-download upstream packages. All builds and releases come directly from this repository.

[Browse the source on GitHub](https://github.com/yusixian/anjian)
