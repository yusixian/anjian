## Reading & direct edits [#read-and-edit]

Documents render rich text—headings, tables, code blocks, images, math, Mermaid diagrams, artifact references, and Q&A/approval cards—with a table of contents for fast navigation.

Click **Edit text** to tweak wording right in the browser. If you see **Not synced** or **Storage quota exceeded**, keep the tab open until the connection or quota recovers.

## Inline comments [#comment-on-text]

Select text or a block to pin a thread in the right sidebar. If the passage is deleted later, the thread stays intact and marks the anchor stale.

## Revision history [#compare-history]

Open **History** to compare any two points in time with **Changes only** filtering. History view is read-only; media files are not archived per revision.

## Rerunning verification checks [#rerun-verification-checks]

Documents with verification reports let you inspect commands and raw output; when code changes, ask your Agent to rerun checks and refresh the report (see [Review Workflows](/en/docs/review-workflows)).

## File layout (for Agents) [#document-source-files]

Documents live in `.anjian/artifacts/document/<id>/` (`doc.xml` LiteXML + `assets/`). Have your Agent read the bundled skill via CLI (setup in [Connect an Agent](/en/docs/agent)) and preserve existing block IDs when editing:

```bash
anjian skills get artifacts
anjian skills get artifacts --reference document.md
```
