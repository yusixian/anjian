## 目录结构与接入 [#页面与资源]

HTML 作品放在 `.anjian/artifacts/html/<id>/` 下，入口为 `index.html`，页面 `<title>` 自动作为作品标题。图片、CSS、JS 放同目录并用相对路径引用。

如需接入案间参数面板或反馈控件，让 Agent 用 CLI 读取指引（配置见 [批注与 Agent](/zh/docs/agent)）：

```bash
anjian skills get artifacts
anjian skills get artifacts --reference html.md
anjian skills get artifacts --reference ui.md
```

## 隔离沙盒与权限 [#隔离预览]

HTML 作品运行在隔离沙盒里，无法访问主工作台的登录态或数据：

- **私有预览**：正常执行页面脚本，也支持划选文字后把选区发给本地 Agent。
- **公开分享**：会拦截外部 API 请求、表单提交和弹窗，建议把需要展示的字体、样式和图片打包进作品目录。

## 排查空白页 [#调试与检查]

1. 检查 `index.html` 结构是否完整；
2. 确认静态资源使用相对路径且都在作品目录内；
3. 运行 `anjian check --artifact html/<id>` 查看路径或语法警告；
4. 打开浏览器开发者工具查看控制台报错或沙盒拦截提示。
