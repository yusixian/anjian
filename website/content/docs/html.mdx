## 页面与资源

HTML 作品由 `.anjian/artifacts/html/<id>/index.html` 和同目录资源组成。标题取自页面的 `title`，图片、脚本和样式使用作品内部的相对路径。

HTML 可以包含自己的按钮、表单外观和交互逻辑。需要参数或反馈控件时，Agent 应执行 `anjian skills get artifacts --reference html.md` 与 `anjian skills get artifacts --reference ui.md`，按案间 runtime 的约定接入；普通 HTML 不会自动获得完整的反馈表单。

## 隔离预览

作品在隔离环境里运行，不能获得主工作台的同源权限。外部依赖、网络请求或弹窗可能受到限制，尤其是在公开分享中。优先将允许分享的依赖放在作品目录内，并实际预览。

公开页面允许内部脚本和只读检查，但禁止外部 API 请求、表单提交和弹窗。因此依赖在线服务的演示不一定能在快照中完整运行。

## 调试与检查

写入文件后运行 `check`，再在浏览器打开作品并操作相关控件。页面未运行时，空的 runtime 警告列表不能证明脚本正常。

如果页面空白，检查入口是否完整、相对路径是否正确、依赖是否在作品目录内，以及浏览器是否报告脚本或沙盒限制错误。

这里的 `anjian` 指构建后的 CLI 或已有包装器；可执行入口与内置 Skill 的发现方式见[批注与 Agent](/docs/agent)。
