# Anjian 的 OpenCode 本地集成

先按 [本地安装](../docs/install.md) 构建工作台，再按当前 OpenCode 版本的本地插件配置方式加载本仓库目录。根目录 `index.js` 与 `.opencode/plugins/anjian.js` 是插件入口。

本项目没有已发布的 GitHub/npm 安装地址，不要使用 `Innei/anjian` 或 `anjian@git+...` 作为安装源。命名空间为 `anjian`，skills 位于本仓库 `skills/`。

本地集成尚需在真实 OpenCode 宿主中验收；不要把工作台构建通过视为宿主集成已通过。
