#### 中文

新增 `anjian feedback-host`，将本地文档批注和画板反馈交给你配置的 Agent 宿主。可在同一监听会话增减作品，各宿主会话单独记录批注已读。安装和操作示例见文档站「批注与 Agent」。

<!-- anjian:en -->

#### English

Use `anjian feedback-host` to send local document and artboard feedback to a configured Agent host. Add or remove artifacts while the listener is running and keep comment read receipts separate for each host session. See Comments and Agents in the docs for setup and usage.
