#### 中文

在桌面画板中选中一个元素，可在检查器里点击「从预览中删除」，也可撤回对应板块的上一次删除。案间会把预览删除的源文件和元素路径提供给 Agent。请 Agent 应用删除后，改动才会写入源文件。

<!-- anjian:en -->

#### English

Select an element on the desktop artboard and click **Remove from preview** in the Inspector. You can undo the last removal for each board. Anjian provides the Agent with the source file and element path for each preview removal. Ask the Agent to apply the removals to save them to the source.
