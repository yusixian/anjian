#### 中文

案间按作品记住启动它的 Agent。同一项目里打开其他作品时，各自的提交按钮和默认回复署名保持对应。

<!-- anjian:en -->

#### English

Anjian remembers which Agent opened each artifact. Opening other artifacts in the same project keeps their submit labels and default reply authors associated with the correct artifact.
