#### 中文

Linux 上可通过 `anjian service` 安装、启停和卸载本机 Hub 的 systemd 用户服务。服务可在登录时启动，并在 Hub 异常退出后自动恢复。停止和卸载保留作品和本机状态。

<!-- anjian:en -->

#### English

Use `anjian service` on Linux to install, start, stop, and uninstall the local Hub as a systemd user service. The service can start at login and recover from an unexpected Hub exit. Stopping or uninstalling keeps artifacts and local state.

<!-- anjian:end -->
