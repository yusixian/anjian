#### 中文

恢复文件或切换、合并 Git 分支后，打开原文档的「恢复文档批注」，核对工作区带入的人工批注后即可合并。也支持导入单独的批注备份文件。合并保留原作者、时间、位置和删除记录。

<!-- anjian:en -->

#### English

After restoring files or switching or merging a Git branch, open **Recover document comments** in the original document to review and merge human comments from the workspace. You can also import a separate comment backup. Recovery keeps authors, timestamps, anchors, and deletion records.
