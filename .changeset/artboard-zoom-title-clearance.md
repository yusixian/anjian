#### 中文

缩远时，画板标题会按相邻板块留出的空间限制放大，避免远景字号遮住板块。标题在缩放时保持原位置和行数，并在指定宽度内折行。有足够空间时，仍使用原来的远景字号。

<!-- anjian:en -->

#### English

When you zoom out, artboard titles use the space available beside nearby boards so the minimum text size does not cause new overlaps. Titles wrap within their configured width, keep the same position and line count while zooming, and use the existing overview size where it fits.
