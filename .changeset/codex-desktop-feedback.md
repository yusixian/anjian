#### 中文

本机 Codex 桌面会话可接收案间的定向反馈。安装或升级案间插件后，在 Codex 的「设置 → 钩子」审查案间 Hook，再从要接收反馈的会话打开作品。已连接的会话收到反馈后可用通知里的命令读取批注。打开不同项目的同名作品链接时，内容和批注各自归属原项目。

<!-- anjian:en -->

#### English

Local Codex desktop sessions can receive routed feedback from Anjian. After installing or updating the plugin, review Anjian’s hooks in **Settings → Hooks** and open the artifact from the session that should receive feedback. The receiving session can read the comments using the command included in the notification. Links to artifacts with the same name in different projects now keep their content and comments in the correct project.
