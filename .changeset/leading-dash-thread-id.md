#### 中文

案间生成的批注 ID 即使以短横线开头，也可以直接传给 `anjian comment read`、`reply` 和 `resolve` 的 `--thread` 参数。

<!-- anjian:en -->

#### English

Thread IDs generated by Anjian now work as `--thread` values for `anjian comment read`, `reply`, and `resolve` even when they start with a dash.
