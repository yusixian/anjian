#### 中文

Codex 桌面端收不到批注时，可以在对应项目运行 `anjian doctor codex`。它报告案间钩子是否缺失、停用或等待审核，方便在 Codex 的「设置 → 钩子」里处理。

<!-- anjian:en -->

#### English

If Codex desktop is missing comment notifications, run `anjian doctor codex` in the affected project. It reports missing, disabled, and unapproved Anjian hooks so you can review them in Codex **Settings → Hooks**.
