#### 中文

案间启动器、CLI、钩子和反馈监听器在 macOS 和 Linux 的进程列表中显示案间名称和版本。macOS Hub 也显示名称和版本，Linux Hub 保留启停所需的实例参数。

<!-- anjian:en -->

#### English

Anjian launchers, CLI commands, hooks, and feedback watchers show the Anjian name and version in macOS and Linux process listings. The macOS Hub is also labeled, and the Linux Hub keeps the instance arguments used to start and stop it.
