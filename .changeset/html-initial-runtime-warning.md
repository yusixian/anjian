#### 中文

新建 HTML 作品时，文件监听器会保留同一份页面已上报的运行错误。实际修改源文件后，旧警告会清除。

<!-- anjian:en -->

#### English

A new HTML preview keeps runtime warnings reported before the first file watcher event. Editing the source still clears old warnings.
