#### 中文

GitHub Releases 提供 Linux x64 和 arm64 安装包。校验并解压后即可运行包内的 `anjian`，包内自带 Node.js。两个架构都用解压后的安装包验证了 Hub 启停和 systemd 用户服务。

<!-- anjian:en -->

#### English

GitHub Releases now provides Linux x64 and arm64 archives. Verify and extract the archive to use the included `anjian` command and Node.js runtime. Both architectures are tested with the extracted archive for Hub startup, shutdown, and the systemd user service.
