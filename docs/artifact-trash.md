# 作品多选与回收站

在作品库点击「选择」，或点击卡片上的勾选按钮，即可多选作品。选择模式下点击卡片只改变选择，不打开作品。Shift 连选、Ctrl/Cmd+A 选择当前筛选结果，Esc 退出选择；搜索或切换项目、作品类型后会清空选择，排序不会清空。

点击「移入回收站」后，确认框列出作品、类型和所属项目。操作完成后可立即撤销，也可从侧栏「回收站」逐项恢复。失败项保留以便重试；网络中断时先查询服务端状态，无法确认时提示刷新。

## 数据范围

- 本地运行：移动当前项目的作品目录及其编辑状态。
- 自托管：移动当前服务器保存的副本，不删除电脑上的原始文件。
- 正文、资源、批注和编辑历史一起保留；恢复沿用原作品链接。
- 回收站保留 30 天，服务器运行期间按小时检查，也会在读取和操作时清理到期内容。停机期间不会执行清理。
- 「永久删除」需要再次确认，确认后内容无法恢复。
- 恢复时遇到相同目录或编辑状态冲突会失败，不覆盖现有文件。

回收站位于项目的 `.anjian/.trash/`，不是操作系统废纸篓。备份时应保留整个 `.anjian/`，包括作品和回收站；备份恢复需另行验证。

## 与 CLI 同步的关系

已删除作品的原类型和 ID 会被服务器拒绝上传，避免下一次 push 自动恢复作品。需要继续编辑时先在回收站恢复；永久删除后如需重新发布，应创建新的作品 ID。

删除记录会在内容清理后保留，用于阻止旧 ID 再次上传。手动绕过案间修改数据目录、多个服务进程同时写入同一项目，不属于此流程的并发保护范围。
