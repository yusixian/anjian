# 公开只读分享

在作品页或作品卡片点击“分享”，选择有效期，再点击“创建公开链接”。画板、文档和 HTML 均支持分享。默认私有；创建分享不会公开项目列表或其他作品，也不会把管理员访问密钥放入链接。

分享发布的是完整作品快照及其资源，画板包含全部页面。访客无需登录，可以阅读、缩放、切换页面和查看预览；不能编辑、评论、读取编辑历史或管理实例。只读无法阻止截图、复制文字或保存已经传输的资源。公开前请检查源文件与附件是否适合分享。

## 更新与关闭

- 修改原作品不会自动更新公开版本。点击“更新分享”才发布新快照；更新保留当前链接和到期时间。
- 创建时可选择 1 天、7 天、30 天或长期有效。过期后重新创建会获得新链接。
- “重置链接”保留已发布内容及到期时间，让旧链接失效。
- “关闭分享”保留原作品与批注，停止公开访问。作品移入回收站或项目移除也会撤销分享；恢复作品或重新注册项目不会自动恢复分享。
- 发布前验证快照；无效、未完成或超限的更新不会替换旧的可读版本。请求中断时，界面重新读取状态，不盲目重复操作。

访问请求和资源请求都检查分享状态，不设置长期公开缓存。已打开的访客页每 30 秒和重新获得焦点时检查状态；确认关闭后移除内容。已经传输、另存或正在完成传输的内容无法收回。

## 预览限制

HTML、画板和文档动态块使用隔离预览地址与沙盒。公开预览允许页面内部脚本，禁止外部 API 请求、表单提交和弹出窗口；依赖外部脚本、字体、图片或接口的演示可能无法完整显示。请把允许公开的依赖放到作品资源目录，再使用“预览访客页面”检查结果。

公开内容通过独立 `/s/<随机标识>` 入口访问，不复用项目内容 token。默认请求搜索引擎不收录，不提供公开作品目录；这不等于保密，持有链接的人可以转发。

## 当前存储与限制

本版分享由统一 Hub 提供。快照位于 `ANJIAN_SERVER_HOME/shares`，标准容器对应 `/data/server/shares`；原作品仍在 `/data/project/.anjian/artifacts`。二者都需要持久化和备份。目前没有 S3 或成员数据库接入。

沿用作品传输限制：单份快照最多 32 MiB、1,000 个源文件；共享快照索引默认总预算 512 MiB。更新时会短暂同时保留旧、新快照，成功切换后清理旧副本。关闭分享清理对应快照；过期快照在后续发布时清理。

匿名入口有进程内请求和传输限流，超限返回 429 与重试时间。它用于抑制突发请求，不是持久化的月度费用预算，也不会阻止反向代理或网络层产生费用。GUI 成员额度、共享 S3、自带 S3 和实例数据库配置属于后续阶段，不能将当前分享功能视为这些能力已经实现。
