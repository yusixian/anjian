# 本地工作台技能对照评估

日期：2026-11-07。范围：`skills/artifacts/SKILL.md`。评估者为未参与实现的只读子代理；这是提示行为评估，不是实际 Agent 会话端到端测试。

| 场景 | v1.51.2 基线行为 | Anjian 修订后行为 |
| --- | --- | --- |
| 本地 CLI 构建缺失 | 调用 launcher，首次可能安装上游发行包 | 在本仓库 artifacts 目录安装锁定依赖并构建，不安装官方发行包 |
| 从手机查看 | 优先 cloudLink，可能发布到官方云 | 使用可达的自有服务器地址，说明 localhost 不可跨设备访问，保留访问密钥 |
| 用户要求无官方云 | 跨设备分享仍引导官方发布、登录 | 本地工作台，无官方登录、发布、订阅；HTTPS、同步和通知需独立验证 |

首次修订的盲读发现两处残留：Codex 启动段仍声称会安装发行包，远程示例仍使用 localhost。均已修正为本地构建与可达地址。依赖安装可能访问软件包仓库，不把“无官方云服务”夸大为首次安装完全离线。
