## 1. 标志：定稿 C2「三层作品」

用户从两轮共 8 个方向里选了 C2，其余方向已从设计稿删除。三张叠放的作品分别对应画板、文档、HTML，最前面一张带一枚批注针；颜色由浅到深都取自品牌陶土色。

### 几何（64×64 网格）

| 元素                       | 位置与尺寸                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| 后层                       | x23 y7，31×37，圆角 6.5                                                                          |
| 中层                       | x16.5 y13.5，31×37，圆角 6.5                                                                     |
| 前层                       | x10 y20，31×37，圆角 6.5                                                                         |
| 批注针                     | 圆心 (24.5, 40.5)，半径 6.5，左下角为直角：`M18 47v-6.5a6.5 6.5 0 1 1 6.5 6.5H19a1 1 0 0 1-1-1Z` |
| 底板（应用图标与 favicon） | 64×64，圆角 15；标志缩放到 0.8 后居中（`translate(6.4 6.4) scale(.8)`）                          |

### 颜色

| 版本 | 底板      | 后层             | 中层             | 前层              | 批注针       |
| ---- | --------- | ---------------- | ---------------- | ----------------- | ------------ |
| 浅色 | `#f6efe6` | `#e5c6b6`        | `#d29881`        | `#b4512f`         | 与底板同色   |
| 深色 | `#2a2521` | `#6c4d40`        | `#a36e5a`        | `#ed9b7d`         | 与底板同色   |
| 单色 | 无        | currentColor 26% | currentColor 55% | currentColor 100% | 镂空（遮罩） |

彩色版用实色而不是透明度，因为透明层重叠处会变深。浅色层为陶土色 26% / 55%，深色层提高到 34% / 62%，否则后层会融进深色底板。

深色界面必须用深色底板版，再加 `box-shadow: 0 0 0 1px rgb(255 255 255 / .09)`，圆角与底板一致（尺寸 × 15/64）。浅色底板放在深色顶栏上会成为整条顶栏唯一的亮块，用户已指出这个问题。单色版用两个遮罩：一个从三层中挖掉批注针，另一个去掉后层被中层盖住的部分。

| 位置                                             | 改法                                                                                                           |

验证：`artifacts/test/server.test.ts` 断言 `href="/anjian.svg"`，路径不变就不受影响。另外要检查：同一页面出现多个标志时，每个的批注针都是镂空的；单色版在深浅顶栏上都清楚；16px favicon 能辨认。

## 2. 文档站视觉打磨（`website/`，Fumadocs）

设计稿共 8 张：首页（浅色、深色、手机）、阅读页「在本机使用」「邀请朋友」（含手机）、使用案例（桌面、手机）。全部是静态设计，交互没有实现。实际数值以 `design-src/gen_docs.py` 的 `CSS` 为准，下面列出要点。

**设计令牌**（浅 / 深）

- 背景 `#fcfbf9` / `#181715`，次级背景 `#f6f3ee` / `#1f1d1a`，卡片 `#fff` / `#23211d`
- 正文 `#25221e` / `#efeae3`，次要正文 `#4b463f` / `#cfc7bd`，弱化文字 `#7b746b` / `#9b9389`
- 分隔线 `#ebe6df` / `#312d28`；强调色 `#b4512f` / `#ed9b7d`；浅强调底 `#f8ece5` / `#33241d`
- 卡片用一圈 1px 半透明阴影加柔和投影，不用实线边框

**排版与通用规则**

- 文字：正文 15px，行高 1.7–1.85；导语 17px；首页大标题 52px（手机 34px）；文档标题 36px（手机 29px）；二级标题 23px。全站最小 12px
- 图标统一线条风格，笔画 1.75；顶栏图标 20px，点击区 38px
- 圆角：卡片 16，按钮和输入 10，小标签 999
- 首页顶部右侧有一层淡陶土色径向光晕

**顶栏（64px，手机 56px）**

- 左侧：标志 28px、「案间」、「文档」胶囊标签
- 导航「使用指南 / 自托管 / 使用案例」，当前项用浅底高亮
- 右侧：搜索框（240×38，带 ⌘K 提示）、主题切换、GitHub 图标。手机只保留搜索和菜单图标

**首页**

- Hero：左边标题与两个按钮（主按钮「开始本机使用」、次按钮「了解全部功能」）；右边 540×420 的工作台示意，手机上等比缩到 0.648
- 「你想从哪里开始？」：三张卡片，每张有图标块、标题、说明和底部链接。手机改成横排，右侧一个箭头
- 「三种作品，同一套批注」：三张卡片，上方是画板、文档、HTML 的小插画。手机不显示插画
- 页脚：「案间 · AGPL-3.0 开源」，右侧 GitHub 与「开源与许可」

**阅读页（三栏：264 / 正文 ≤ 800 / 236）**

- 侧栏：分组标题用 13px 半粗体，当前项用浅强调底加强调色
- 正文依次是：面包屑（箭头分隔）、标题、导语
- 环境信息条：一行三格，分别是运行环境、包管理器、安装方式
- 提示框：浅强调底，左侧一个信息图标
- 编号步骤：32px 圆形编号，相邻步骤之间有竖线连接
- 代码块：顶栏显示终端图标、说明和复制按钮；命令名用强调色，参数用弱化色
- 上一篇 / 下一篇做成两张卡片
- 页内目录：当前项左侧 2px 强调色竖线；底部「发现错误？在 GitHub 反馈」
- 手机：隐藏侧栏和目录，换成「文档导航 / 本页目录」条

**使用案例页**

- 1→2→3 步骤流程（手机竖排）
- 两张截图卡片，每张有步骤标签、标题、说明、带 1px 描边的截图和图注
- 底部一条说明，带「查看公开作品」按钮

文档站标志按主题切换：浅色用 `anjian.svg`，深色用 `anjian-dark.svg` 并加上述描边（Fumadocs 可用 `.dark` 类切换图片，或改成内联 SVG）。favicon 固定用浅色版。
