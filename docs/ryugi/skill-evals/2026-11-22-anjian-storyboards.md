# 分镜工作流的 Skill 对照

让独立评估会话准备一段产品演示，在两条视频轨道叠放画面，混入旁白，并在移动片段后找回批注。最后交付和预览时序一致的可播放文件。

基线 `a231a89` 的画板指南可嵌入外部导出的 MP4，并关闭自动裁切来保留时长。它只有画板级定位，缺少可编辑时间线、音轨混音和稳定的片段 ID，也缺少从同一次渲染生成预览与下载的流程。

候选指南让评估会话在 `storyboard/product-demo` 中写 `timeline.json` 和 `assets/`。把叠加画面放到靠后的轨道，把旁白放到音频轨道，移动片段时保留 ID。通过 `comment list` 中的 `anchor.clipId` 找到原片段，按线程回复。保存后渲染，试听成片，再下载同一次渲染的 MP4。远程指南同时说明推拉与按片段评审的入口。

这次对照核对操作指引。实际画面边界、混音、导出字节和权限由 FFmpeg、HTTP 和浏览器验收覆盖。
