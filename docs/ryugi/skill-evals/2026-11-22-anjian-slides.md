# 幻灯片工作流的 Skill 对照

让独立评估会话准备三页发布演示，在浏览器重排幻灯片后回复原来第二页的批注，最后向匿名客户交付演示并保留私密的讲者备注。

基线 `04d711a` 的类型指南会选择画板，写 `canvas.json` 和 `pages/`，通过 `--board` 定位批注。它缺少编辑卡组、稳定页 ID、讲者备注和匿名发布的流程，连贯完成该任务需要猜测接口。

候选会话选择 `slides/pitch`，写含三个稳定 ID 的 `deck.json`，并重排 `slides` 数组。它用 CLI 返回的 `anchor.slideId` 找到原评审页，再按线程回复。浏览器从放映进入讲者视图。公开交付前保存并通过 Share 发布快照，交付生成的匿名 URL。公开快照保留幻灯片标题与正文，讲者备注和批注留在项目中。
