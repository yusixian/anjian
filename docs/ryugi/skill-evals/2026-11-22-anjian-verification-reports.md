# 案间验收报告指引验证

用同一只读场景分别测试原有 `verifying-ui` 指引和新增的 `verifying` 指引。任务要求在报告里保留机器日志、构建和采集时间，链接视觉验收组，注明 Windows 无设备，并处理次日替换两种证据。两名独立 Agent 分别阅读对应版本。

- 基线通过正文、日志摘录和画板引用组织报告。画板可以重新判定，日志摘录不能恢复完整原始输出，也缺少证据变更检测。
- 候选给出清单、证据摘要与生成命令，并保留完整日志。报告重生成时根据原摘要判断证据是否仍可支持原结论。候选正确指出已有文档是一次捕获的记录，画板引用始终显示当前状态，需要回看旧截图时应保留原验收组。未提供的真实命令和时间保留待补。

## 运行记录

- 本机构建 CLI 生成案间文档。隔离 Hub 与 Chrome 在 1440 px 显示并展开完整原始输出，显示 Windows 覆盖缺口，显示关联验收组的测试通过状态。替换组内证据后原通过自动回到待验收。替换日志并重生成后，390 px 浏览器显示待复核，也未显示未经复核的新内容。
- 自动化回归覆盖报表解析和 XML 往返、原始输出特殊字符与 BOM、缺失及修改证据、拒绝覆盖清单或证据，以及保留私有报告的文件权限。
