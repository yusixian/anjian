# 案间设计规范工作流验证

对照 Ryugi v1.101.1。既有案间能力包括画板验收组、作品引用和验收报告。本批补充可复用的规则清单，以及验收报告中的规范修订和逐条证据关联。

## Agent 指引对照

同一任务交给独立的 GPT-6.2 Sol Agent。场景要求将已经选定的新建入口沉淀下来，复用当前截图测量和画板验收组，同时只交付一份结果。每轮可见相同的 CLI 命令摘要，文档指引按阶段切换。

| 阶段       | 可观察结果                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 原文档指引 | 建议生成一份规范并引用画板，未固定规范修订，也未把规则 ID 传给验收报告。                                                                          |
| 首稿       | 知道给规则分配稳定 ID 并保存版本化 JSON，仍把规范视为唯一交付物。                                                                                 |
| 修订后     | 保存原始规范，按要求只交付验收报告链接。报告用文件、SHA-256 和规范文档地址固定修订，机器检查和人工验收填入同一套规则 ID。未覆盖的规则标为未检查。 |

这里只评估每轮的可观察操作计划。浏览器和 CLI 由独立集成验收执行。

## 实际验收

在隔离案间服务中，用仓库现有的作品引用卡片完成一次规范和验收。Chrome 在 1440px 桌面和 390px 手机视口测量辅助文字字号、长标题和页面宽度，并将测量输出写入报告。实际卡片完整显示长标题，两种视口的页面宽度均与视口一致。报告打开规范文档，并标明未测的主题对比度。

另存第二份规范并改变布局规则后，原报告仍显示第一版规则。将新版文件与原版摘要配对会报错。旧的验收报告输入输出仍有回归测试覆盖。
