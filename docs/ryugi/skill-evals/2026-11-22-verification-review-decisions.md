# 规格工作单保留验证

对照案间 `e7021f7` 与 #95 的工作区改动。每次给独立 Agent 相同场景，只提供对应版本的 `skills/executing-specs/SKILL.md`。

- 场景一。UI 分支已提交审查修复，人工验收和合入均未完成。台账有会改变重试的决定、内部命名、用户可见的延期项和内部延期项。
- 场景二。无 UI 的分支允许合入，但还有独立的人工作业批准待完成。

基线 Agent 按 Finish 指引先删除规格工作单，再进行 UI 验收。两个场景都要求在最终回复列出全部台账决定和延期项。

新版 Agent 在两个场景都保留完整台账到合入，只在报告或回复列出改变用户行为的决定及延期项，并交代等待的验收或批准。第一次复核定位到审查规则及示例中的旧指示。同步这些段落后重跑，两个场景均给出相同的保留和汇报动作。
