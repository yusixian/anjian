# 手机样机引导验证

同一场景交给两个独立的 GPT-6.2 Sol Agent。任务是在一张画板上比较 390 × 844 的机票改签方案，复用项目设计约定，只改变确认按钮的位置，并支持桌面和手机审阅。

| 指引           | 实际输出                                                                                                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 原有画板指引   | 找到普通启动、画板尺寸和选择组。将设备边界、安全区和系统栏作为自行声明的假设。                                                                                                           |
| 含手机样机指南 | 找到 `start --mockup`，在同组放置两张完整样机。使用相同航班、价格、组件和设计令牌。显式写入顶部 47 px、底部 34 px 的示例安全区，在画板便签注明假设。为固定按钮预留完整高度和底部安全区。 |

第二轮指出，样机的 CSS 尺寸与手机端画板缩放应分别验收。最终指南明确这两项检查。

## 运行验证

隔离 Hub 的启动器返回 `mockupGuide`，`check` 无警告和未就绪作品。Chrome 用 1440 px 桌面和 390 px 模拟手机视口打开同一画板。桌面显示两张 390 × 844 的方案，手机能展开并换到第二张，向上拖动可看到固定按钮；两端均无页面横向溢出。桌面提交的批注保存在固定按钮方案的锚点。按原始页面尺寸测量时，两版 48 px 高的按钮都位于屏幕安全区内。
