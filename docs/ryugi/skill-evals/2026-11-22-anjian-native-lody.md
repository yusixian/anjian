# 原生作品 Lody 评审指引对照

任务是在自托管项目中处理一个非默认白板页的图形批注、一个重排过的幻灯片批注和一个片段批注。收到任务后保存新修订，重新提交同一结果，并由浏览器验收。

基线 `e1a6c19` 的远程指南只为文档和画板说明显式提交。原生作品的指南可以通过 CLI 手工读取和回复批注，连接校验只接受 `document` 和 `artboard`。在该路径上创建白板或幻灯片的 Lody 连接会在类型校验时被拒绝。

候选指南要求在编辑器里选择批注并显式提交。Agent 用白板页和元素 ID、幻灯片 ID 或片段 ID 确定修改位置。认领后的源修订和一份完整源文件清单进入持久结果，操作 ID 与清单保持一致以便重试。其他页、讲者备注和媒体按原样纳入源文件清单，由浏览器验收回传结果。
