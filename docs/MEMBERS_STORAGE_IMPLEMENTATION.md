# 成员与存储实施记录

目标：管理员通过网页邀请 GitHub 成员、分配共享存储额度；成员使用独立个人空间，并可在网页配置自己的私有 S3。既有 Owner、作品、设备和公开分享保持兼容。此文档记录实施状态，不代表功能已上线。

## 当前证据与顺序

2026-11-10 审计：GitHub OAuth 只接纳 Owner；`hub.ts` 将身份折叠为布尔授权，作品列表、回收站、分享、设备批准与服务控制共用它。`route()` 按 URL/Referer/首个项目选挂载，挂载使用全局服务器密钥。`routes/content.ts` 的随机 `/c/` 路径和独立预览域名不校验成员。直接放开 OAuth 会让成员继承管理员权限，因此邀请登录须在全部入口隔离后启用。

1. **身份和归属。** 持久化 GitHub ID、邀请、成员状态、会话版本和项目归属；旧项目和旧设备默认属于 Owner。GitHub 用户名只用于显示，鉴权绑定不可变的数字 ID。邀请 token 仅保存哈希，绑定账号、到期、单次使用；暂停后旧会话不能在恢复时复活。
2. **完整访问边界。** 将 Owner、Member、Device 作为明确身份。所有 HTTP、WebSocket、源文件、预览、历史、下载、回收站、分享操作都按项目归属检查。服务控制、全局日志和实例设置仅 Owner 可用。成员不能收到全局密钥、磁盘路径或他人设备信息。成员暂停后既有 WebSocket 与设备也失效。
3. **GUI 成员流程。** 邀请、受邀账号核对、加入、个人空间、额度修改、暂停与恢复。CLI 配对只展示和批准本人项目。注册成员空间不能接受任意磁盘路径。
4. **存储适配。** 保留文件系统后端，为资源和发布快照接入私有 S3。先盘点文档/画板源文件、资源、历史、回收站与快照的读写生命周期，避免只上传新文件而遗漏已有读取路径。服务器仍保有必要元数据；GUI 明确 S3 容量不等于数据库或中转配额。
5. **GUI 存储与额度。** Owner 配共享 endpoint、bucket、region、凭据、总预算与成员额度；成员仅能配自己的凭据。凭据服务端加密，响应只给掩码；连接测试验证真实读写删除权限并清理测试对象。自定义 endpoint 防 SSRF、重定向与 DNS 重绑定。未配置真实凭据时显示待配置，不声称已接入。
6. **额度和迁移。** 并发写入先预留额度，失败释放，成功结算；纳入快照与回收站保留数据。迁移有持久进度、校验、失败重试和中断恢复，校验后切换读取。旧文件保留，清理单独确认；不能把迁移失败当成功或重复计费。

## 必须验证的交付边界

- 两个成员、Owner、设备、匿名访客交叉访问矩阵，包括猜测 URL、Referer、项目参数、`/c/` 源文件、独立预览域名、WebSocket 与已建立连接。
- Owner 原会话、旧项目/设备及原公开链接兼容；成员禁用后访问立即失效。
- S3 自定义 endpoint、凭据掩码/加密、失败诊断；使用受控兼容服务验证适配，真实外部 bucket 配置另行验证。
- 并发上传额度、覆盖/删除/回收站/分享计费、迁移断点和重试一致性。
- GUI 桌面/手机配置、邀请与错误状态的真实浏览器验收；提交、CI、部署与生产验证分别记录。

## 实施进度

- 已新增 `member-store.ts` 基础存储：绑定 GitHub 数字 ID 的邀请、暂停/恢复会话版本、额度记录和项目归属。
- OAuth 新增 `principal()` 返回明确身份，支持签名流程绑定邀请；旧 `authorized()` 仍严格只认 Owner。尚未向生产 Hub 传入成员存储，因此线上仍只允许 Owner，不能把这一基础改动视为多人功能可用。
- 成员存储与 OAuth 的 26 项测试通过，覆盖错账号、撤销/替换/过期邀请、暂停后旧会话不复活、旧 Owner 会话兼容、写盘失败和损坏文件拒绝访问。
- `project-access.ts` 已接入 Hub 项目选择和挂载服务。Owner 保留对登记项目的管理权限，成员按项目归属及会话版本检查；不能用 Header、Referer、query 改变身份。项目策略/Hub/Owner OAuth 浏览器/设备 API 的 32 项测试通过。
- WebSocket 已增加入站、广播前鉴权和空闲连接失效检查，成员元数据不可用时关闭连接。WebSocket/Hub/路由回归 33 项通过，类型检查通过。
- 聚合作品列表、回收站和分享已按请求身份过滤；成员侧使用不含磁盘路径的项目编号。等待项目锁、暂停挂载及文档准备后重新检查权限。回收站范围与现有 Owner 分享/Hub 回归 34 项通过。
- CLI 设备增加批准者 ID/会话版本，设备列表与批准项目按成员过滤；暂停或版本变更使 token 失效，批准后失权的待兑换凭证不能创建新设备。无归属字段的旧设备保留为 Owner。设备授权/远程 API/Hub 回归 38 项通过。
- 自托管私有内容与独立画板预览已改为绑定身份版本、项目和作品的随机路径，30 分钟有效；每次读取重验项目权限，旧 `/c/` 私有入口关闭，本地模式及公开分享入口保留。路径是限时 bearer 凭证，持有者在有效期内可读取对应作品资源，不等同于公开发布快照。服务重启后凭证失效，重新读取元数据可获得新凭证。
- 私有凭证、实际 HTTP 资源请求、独立预览与公开分享/Hub/访问控制回归共 49 项通过，类型检查通过。作品页和独立预览页增加到期前续期与回到前台检查；浏览器实测仍待完成。
- 新增 Owner 专属成员 API：查询成员/有效邀请、按 GitHub 用户名查询数字 ID 并创建邀请、撤销邀请、调整额度、暂停/恢复。拒绝成员/匿名/跨站调用，外部查询后再次校验权限；邀请 token 仅在创建响应返回一次，列表不返回 token 或哈希。API/存储/Hub 共 36 项测试通过。
- 登录页支持邀请链接及签名 OAuth 流程绑定，取消授权后保留邀请重试。此入口尚未接通 Hub 的成员会话和个人空间创建；目前仅为实现中的基础流程，不能向朋友交付邀请链接。
- 尚待：生产 Hub 接纳成员、成员 GUI、S3 适配及 GUI、额度预留、迁移、完整验收和部署。尚未开放多人登录。
